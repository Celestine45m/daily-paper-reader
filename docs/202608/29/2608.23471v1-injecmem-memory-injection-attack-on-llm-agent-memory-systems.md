## 摘要
记忆正成为已部署LLM智能体中的默认子系统，以提供持久的个性化和连续性。这自然引出一个问题：记忆系统是否会给智能体引入新的漏洞？为此，我们提出了InjecMEM，一种新颖的记忆注入攻击范式，仅需一次交互（无需对记忆存储的读/写访问权限）即可将相关查询的后续响应引导至预先指定的输出。在记忆系统“先检索后生成”机制的指导下，我们构造了注入，包含一个与检索器无关的锚点和一个对抗性命令。该锚点包含高召回率的主题线索，使得下游检索持续将记录与目标主题关联。该命令是一个经过优化的短序列，能在不确定的融合上下文、可变放置位置和长提示下保持有效，从而在检索到后可靠地引导输出。我们通过基于梯度的坐标搜索学习该命令，对合成提示模板和插入位置进行平均，并将其扩展到跨骨干模型的联合优化以研究迁移性。在多个记忆系统和骨干模型上的评估表明，InjecMEM实现了可靠的主题条件检索和定向生成，在记忆漂移下仍然有效，且不影响非目标查询。我们的结果强调了加固记忆系统的必要性，并提供了一个可复现的框架来研究智能体记忆。

## Abstract
Memory is becoming a default subsystem in deployed LLM agents to provide persistent personalization and continuity. This naturally prompts a question: will memory system introduce new vulnerabilities into agents? Thus we propose InjecMEM, a novel memory injection attack paradigm that requires only a single interaction (no read/edit access to memory store) to steer later responses of related queries toward a pre-specified output. Guided by the retrieval-then-generate mechanism of memory systems, we craft the injection with a retriever-agnostic anchor and an adversarial command. The anchor contains high-recall topical cues so that downstream retrieval consistently associates the record with the target topic. The command is a short sequence optimized to remain effective under uncertain fused contexts, variable placements, and long prompts so that it reliably steers outputs once retrieved. We learn the command via gradient-based coordinate search, averaging over synthetic prompt templates and insertion positions, and extend it to joint optimization across backbones to study transfer. Evaluated across multiple memory systems and backbone models, InjecMEM achieves reliable topic-conditioned retrieval and targeted generation, remains effective under memory drift, and leaves non-target queries unaffected. Our results underscore the need to harden memory systems and provide a reproducible framework for studying agent memory.

## 2. 方法论

### 2.1 核心思路
- 将攻击注入设计为两部分组合：
  - **检索器无关锚点（retriever-agnostic anchor）**：负责让恶意记录在目标主题查询下被稳定检索。
  - **对抗命令（adversarial command）**：负责在恶意记录被检索并融合到最终提示后，引导LLM输出目标内容。

### 2.2 锚点构造
- **窄主题**：在锚点中加入直接指令，使关键词LLM输出目标主题词；同时附加一段简短的、描述主题代表性的片段，兼顾关键词匹配与语义相似度。
- **宽泛领域**：构造**质心式锚点**——包含领域标签、高召回关键词（如health领域用 ache、symptom、treatment）、以及领域内常见意图列表。这种方式将记忆的摘要表示拉向领域语义中心，提高未来多样化查询的检索命中率。

### 2.3 对抗命令优化（Multi-GCG）
- 目标：在动态融合上下文、可变插入位置、长提示稀释下仍能有效引导生成。
- 方法：基于梯度的**坐标搜索**，将多个合成代理提示（surrogate prompts）和多个插入位置作为训练分布，对平均负对数似然进行优化。
- 损失函数形式：  
  `L(c) = E_{(i,p)} [ -log P_θ( y* | C_{i,p}(c) ) ]`
- 更新方式：对每个token坐标计算梯度 → 取Top-K候选 → 在宽度W内随机替换R个位置 → 选取使损失最小的候选字符串。通过同时覆盖多上下文、多位置、多长度来增强鲁棒性。

### 2.4 迁移扩展
- **FJ-Multi-GCG（Family-Joint）**：针对共享tokenizer的同一模型家族，在两个骨干上联合优化一个命令，提升对家族内未见变体（如3B/14B）的迁移性。
- **CF-Multi-GCG（Cross-Family）**：针对不同tokenizer的模型家族，以规范字符串为共享表示，通过跨tokenizer梯度映射与联合评估，尝试跨族迁移。
- **Concat策略**：简单拼接各骨干独立优化的命令，可在多个模型家族同时获得非平凡成功率。

### 2.5 威胁模型
- 攻击者只能与智能体交互**一次**；无法读取或修改记忆存储；对记忆子系统内部（嵌入器、关键词LLM等）视为黑盒；但允许对骨干LLM进行白盒访问（用于优化命令）。

## 3. 实验设计

### 3.1 数据集与场景
- **合成数据**：跨19个领域（健康、金融、农业、法律等）构造944个多轮对话，共3096页，用于预填记忆和触发记忆漂移；并为每个领域生成约50个测试查询。
- **真实数据**：额外使用WildChat（真实用户–ChatGPT交互）中的健康与金融主题，验证攻击在真实对话分布下的有效性。
- **记忆系统**：主要评估MemoryOS；另在MemGPT上验证可迁移性。
- **骨干模型**：主用Qwen2.5-7B-Instruct；另包括Qwen2.5-1.5B/3B/14B、LoRA微调7B、Mistral-7B-Instruct-v0.3、Llama-3.1-8B-Instruct。

### 3.2 对比方法
- 检索侧基线：LLM生成的**on-topic paragraph**锚点。
- 生成侧基线：**DPI（直接提示注入）**、**BadChain（思维链后门）**、**GCG（通用对抗触发）**。
- 另与 **AgentPoison**、**MINJA** 进行攻击设置对比（在附录中）。

### 3.3 评价指标
- **RSR**：检索成功率（条件为检索到注入页面），区分首次命中与多轮累计命中。
- **ASR-c**：给定检索成功时，输出等于目标的比例。
- **ASR-j**：端到端攻击成功率 = 检索成功且输出为目标。
- **BBR**：防御评估中良性页面被误拦截比例。

## 6. 主要结论与发现

- InjecMEM在MemoryOS上显著优于基线：
  - RSR在不同领域和查询次数下可达到约35%~61%（@1），高于对主题段落基线。
  - ASR-c达到76.6%，ASR-j达到35.6%；DPI、BadChain、GCG在动态融合场景下全部失效。
- 在MemGPT上攻击有效但成功率略低（RSR 37.2%，ASR-c 48.6%，ASR-j 18.1%）。
- **族内迁移**：7B优化命令在LoRA微调7B上有效，但迁移到3B/14B很差；FJ-Multi-GCG显著提升族内迁移。
- **跨族迁移**：单一命令跨族零样本迁移困难；跨族联合优化只对优化过的家族有效；Concat-3方法可同时覆盖Qwen、Mistral、Llama三个家族。
- **防御效果**：LLM-as-Judge、ProtectAI、PromptGuard能降低但无法消除攻击；困惑度过滤会以高良性阻断率为代价才能完全阻断。
- 间接注入场景：通过受损工具（如恶意邮件内容）也可将攻击写入记忆，且工具修复后记录仍持久生效，说明记忆系统是安全边界。

## 7. 优点

- **问题新颖且重要**：首次系统化研究LLM智能体记忆系统的注入攻击，与静态RAG投毒有本质区别。
- **攻击设计解耦清晰**：检索锚点与生成命令分离，各部分职责明确，便于优化与验证。
- **鲁棒性优化考虑周全**：Multi-GCG将多上下文、多位置、多长度纳入优化分布，对应真实动态记忆场景。
- **迁移研究成体系**：从单模型到族内联合、跨族联合、命令拼接，层层深入，提供了实际攻击可行性分析。
- **实验规模较广**：多记忆系统、多骨干、多领域、防御、真实数据均覆盖；指标同时评测检索与生成，端到端指标（ASR-j）避免了单一环节误导。

## 8. 不足与局限

- **白盒假设局限**：最强的生成侧攻击需要白盒访问骨干模型；虽然论文用迁移缓解，但在现实黑盒场景下能否稳定优化仍是问题。
- **跨族泛化差**：跨模型家族零样本迁移基本失败，联合优化也无法覆盖未见的家族；约束了攻击的普适性。
- **应用范围受限**：攻击仅适用于存储原始交互文本的记忆系统；对写入前做重写/摘要的记忆管线不适用。
- **目标输出性质**：实验使用的目标输出是“FUCK YOU!...”，虽便于客观指标检测，但并非实际有害指令；尚未验证对更有害/操作性输出的控制能力。
- **防御评估较浅**：仅测试了标准检索时过滤，未考虑专门针对该攻击的检测、写入时净化或输出监控等。
- **算力与资源未披露**：无GPU/时长信息，复现难度增加。
- **真实数据评估规模小**：仅健康、金融两个主题，且来自同一数据集（WildChat），代表性有限。
- **未报告失败案例模式**：对攻击失败（如某些领域RSR低）的原因分析较少，限制了对边界条件的理解。
