## 摘要
大型语言模型（LLM）仍然容易受到越狱攻击的影响，这些攻击利用角色扮演、混淆、代码转换和多步间接等技术来诱导有害输出。随着越狱策略不断涌现，防御措施也在持续猫鼠游戏中激增，但大多数防御措施仍是静态的：其安全行为在部署时固定，因此无法积累防御经验或适应未见过的策略。我们提出了一种围绕持久、跨交互规则记忆构建的自我进化测试时防御：当攻击成功时，该框架将失败抽象为一条方法级规则，捕获结构性的攻击包装而非有害主题，并针对未来输入重用该规则。由于规则是方法级的，一条诱导规则可泛化到整个攻击家族，并且随着新包装的出现，标签空间会扩展。该机制完全通过外部记忆和提示操作，无需更新参数，适用于开放权重和黑箱API模型。我们将其实现为四个协作模块，但贡献在于基于记忆的适应机制，而非模块分解。在四个黑箱越狱家族和多个模型上，我们的方法显著降低了攻击成功率，同时保持良性效用，在自适应复合包装攻击下保持鲁棒性，并且随着记忆增长不会增加过度拒绝。

## Abstract
Large language models (LLMs) remain vulnerable to jailbreak attacks that exploit techniques such as role-playing, obfuscation, code transformation, and multi-step indirection to elicit harmful outputs. As jailbreak strategies keep emerging, defenses have proliferated in an ongoing cat-and-mouse game, yet most remain static: their safety behavior is fixed at deployment, so they cannot accumulate defensive experience or adapt to unseen strategies. We propose a self-evolving test-time defense built around a persistent, cross-interaction rule memory: when an attack succeeds, the framework abstracts that failure into a method-level rule capturing the structural attack wrapper rather than the harmful topic, and reuses it against future inputs. Because rules are method-level, one induced rule generalizes across an entire attack family, and the label space expands as novel wrappers appear. The mechanism operates entirely through external memory and prompting, with no parameter updates, and applies to both open-weight and black-box API models. We realize it as four cooperating modules, but the contribution is the memory-based adaptation mechanism, not the module decomposition. Across four black-box jailbreak families and multiple models, our method substantially reduces attack success rates while preserving benign utility, remains robust under an adaptive composite-wrapper attack, and does not increase over-refusal as the memory grows.

## 2. 方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想

- 构建一个**持久的外部规则记忆** $R_t$，初始为空，每次成功攻击后通过学习（归纳）新增规则，实现跨交互的知识积累。
- 规则采用"**方法级标签 + 结构性包装描述 + 拒绝约束**"的规范形式，与具体的有害主题解耦，从而获得跨实例的泛化能力。
- 所有自适应过程通过**外部记忆和提示**完成，**不涉及任何模型参数更新**，适用于黑盒API模型。

### 2.2 规则记忆的形式

每条规则 $r_i \in R_t$ 的规范形式为：

> **[标签 $L_i$] 如果请求使用 $P_i$，则执行 $D_i$**

其中：
- $L_i$：方法级攻击标签（如 `roleplay-nested-persona`）；
- $P_i$：结构性攻击包装描述；
- $D_i$：拒绝约束（即应如何拒绝该类请求）。

### 2.3 五个核心算子

| 算子 | 功能 | 实现方式 |
|------|------|----------|
| **攻击模式分类器 $\phi$** | 将输入映射为一个方法级标签 | 单次LLM调用；若包装匹配已有标签则复用，否则返回 `other` 或 `benign`；标签空间**自动扩展** |
| **规则检索匹配 (match)** | 根据分类标签从记忆中选择触发规则，最多$K=2$条 | 三阶段：标签精确匹配 → LLM相关性打分 → 关键词词法回退 |
| **策略算子 $g$** | 将触发规则映射为响应策略 | 三档：`hard-refuse`（硬拒绝）/ `soft-refuse`（软拒绝）/ `allow`（允许）；冲突时按硬拒绝 ≻ 软拒绝 ≻ 允许排序 |
| **违规检测器 $h$** | 判断当前响应是否构成成功攻击（触发学习信号） | LLM-as-judge，对响应进行1–10危害评分，阈值$\tau=7$；检测模型与外部评估模型异源，避免优化偏差 |
| **规则归纳 $F$ + 记忆更新 $U$** | 生成新规则并更新记忆 | 语义去重 + 每标签容量上限$C=4$，防止过度专门化 |

### 2.4 四智能体实现（仅是实现载体，非核心贡献）

- **A1（规则触发智能体）**：对应 $\phi$ 和 match，对输入分类并检索相关规则。
- **A2（策略决策智能体）**：对应 $g$，根据触发规则决定响应策略。
- **A3（响应生成智能体）**：对应 $f_\theta(x; \pi)$，将策略动态注入系统指令，硬拒绝模式下执行严格安全契约。
- **A4（自我反思智能体）**：对应 $h$、$F$、$U$，检测违规并在必要时归纳新规则、更新记忆。

### 2.5 推理流程（Algorithm 1）

每个交互步骤 $t$ 的完整流程：

1. **分类**：$z^{(t)} \leftarrow \phi(x^{(t)})$，将输入分类为方法级攻击标签（或 benign/other）；
2. **触发**：$R_t(x^{(t)}) \leftarrow \{r_i \in R_t \mid \text{match}(z^{(t)}, r_i)\}$，选出最多 $K=2$ 条规则；
3. **决策**：$\pi(x^{(t)}) \leftarrow g(R_t(x^{(t)}))$，确定响应策略；
4. **生成**：$y^{(t)} \leftarrow f_\theta(x^{(t)}; \pi(x^{(t)}))$，注入策略后生成响应；
5. **检测**：$v^{(t)} \leftarrow h(x^{(t)}, y^{(t)})$，判断是否违规；
6. **学习**：若 $v^{(t)}=1$ 且 $z^{(t)} \neq \text{benign}$，则归纳新规则 $r_{\text{new}} \leftarrow F(x^{(t)}, y^{(t)})$ 并更新记忆 $R_{t+1} \leftarrow U(R_t, r_{\text{new}})$；否则记忆不变。

## 6. 主要结论与发现

1. **显著降低攻击成功率**：在全部4类攻击、3个模型上，本文方法均取得最低的ASR（ASR-gpt大多降至1%以下），大幅优于静态提示、实例级自我提醒和现有智能体防御。
2. **保持良性效用**：在MMLU和GSM8K上，与无防御模型相比性能变化在约2个百分点以内，说明防御增强未以可用性为代价。
3. **自我进化有效**：从第1轮到第2轮，ASR从较高水平急剧降至接近零，证明方法级规则具有跨实例的家族级泛化能力；无防御基线始终保持高ASR，排除了模型本身鲁棒性的混淆因素。
4. **对自适应复合包装攻击鲁棒**：在专门设计用于规避规则触发的复合包装攻击下，方法仍保持稳健。
5. **不加剧过度拒绝**：记忆从空到积累四个攻击家族后，XSTest上的过度拒绝仅从3.6%升至9.6%，说明方法级规则不会因记忆增长而显著伤害良性请求。
6. **规则泛化优于提示级修补**：存储为可复用的方法级规则并通过选择性触发应用，比逐提示修正（如Self-Reminder）和静态提示（Defense Prompt）更稳健。

## 7. 优点与亮点

- **机制层面的创新**：核心贡献是"持久化、跨交互的规则记忆 + 选择性触发"机制，而非模块分解本身。这种机制设计使其具有概念上的普适性和实现上的灵活性。
- **方法级抽象的精妙设计**：从单个失败实例中提取结构性包装规则，实现"一条规则覆盖一个攻击家族"，极大提高了防御知识的复用效率。
- **无需参数更新，兼容黑盒模型**：所有自适应通过外部记忆和提示完成，直接适用于API模型，比白盒防御（SafeDecoding、GradSafe等）适用范围更广。
- **严格且诚实的评估协议**：冷启动在线评估、评估信号与学习信号异源分离、无评估集泄漏，使结果更具可信度。
- **计算开销可控**：稳态下每次交互仅3次LLM调用（分类、策略、生成），相对于单次调用为3.07×调用数、1.43×延迟，与AutoDefense相当，换来的是跨家族的显著鲁棒性提升。
- **超参数不敏感**：K和C在评估范围内不影响结果，降低了调参负担。
- **设计了自适应复合包装攻击的稳健性验证**：主动考虑对抗性规避场景，增强了结论的说服力。

---

## 8. 不足与局限

### 8.1 实验覆盖范围的局限

- **攻击面有限**：仅覆盖4种代表性的提示级黑盒攻击家族；多轮对话攻击、agentic攻击、白盒攻击（如梯度优化攻击）不在评估范围内，泛化结论需谨慎外推。
- **计算约束限制了扩展**：论文明确承认"由于计算约束"未覆盖全部

近期攻击"的解释；此外，多语言场景、对抗性提示变体自动生成、以及更复杂的上下文依赖攻击（需结合对话历史才能识别的攻击）均未验证。以上因素使得本文结论的适用范围被限定在"提示级、单轮、英语、黑盒"这一子空间内。

### 8.2 方法机制本身的局限

- **对新颖包装模式的初始盲区**：方法本质上是"从失败中学习"，因此面对一个与记忆中所有标签都不同的全新攻击家族时，第一轮仍会失败（冷启动暴露）。只有当违规被检测器 $h$ 捕获并成功归纳规则后，后续同类攻击才被阻断。若攻击者每次只使用全新的包装，防御方将始终处于"慢一拍"的被动地位。
- **规则归纳质量依赖 LLM 的抽象能力**：规则归纳算子 $F$ 依赖 LLM 从单次攻击中正确提取"结构性包装"。如果攻击的包装足够隐晦、嵌套层次过深或与内容高度纠缠，LLM可能提取出过泛（误伤良性请求）或过窄（无法覆盖家族内其他变体）的规则，且错误规则一旦写入记忆，在容量上限 $C=4$ 被填满之前不会自动淘汰。论文未讨论错误规则的修正/遗忘机制。
- **标签空间的开放性是把双刃剑**：分类器 $\phi$ 的标签空间虽然可自动扩展，但若面对大量噪音输入，标签可能碎片化（每个样本产生一个新标签），导致记忆膨胀、检索效率下降。尽管去重和容量限制缓解了这一点，但在极端多样化攻击流量下的行为尚未验证。
- **策略决策粒度的有限性**：$g$ 只输出三档策略（允许/软拒/硬拒），对需要"部分回答"或"条件性回答"的场景缺乏中间态。例如，对某些包含危害成分但也有合法用途的请求，三档策略可能不够细致。

### 8.3 评估方法论的局限

- **LLM-as-judge 的固有偏差**：ASR-gpt 依赖外部 GPT-4o-mini 评判，而系统内部检测器 $h$ 同样是 LLM。尽管两者异源，但 LLM 评判本身存在对特定措辞风格的偏好、对长文本的理解不稳定、以及被对抗性输出欺骗的可能性，这在现有研究中已被反复证实。
- **攻击评估的顺序效应**：冷启动在线协议中，攻击按固定顺序流式输入。由于规则归纳依赖先前输入，**攻击顺序会影响后续防御表现**。论文未做顺序敏感性分析——若将最先暴露的攻击调换顺序，各攻击族的 ASR 曲线可能不同。
- **良性任务评估的局限性**：MMLU 和 GSM8K 均为标准学术基准，不能代表真实世界多样化用户请求分布；XSTest 的安全集规模有限（约 200 条）。过度拒绝的评估虽然展示了一个方向，但样本量偏小。
- **缺乏对记忆增长长期行为的追踪**：实验集中在约 20 条/轮的短序列内，记忆中的规则数量较少。当记忆持续累积到数百条规则时，检索准确率、延迟、标签冲突等问题的表现均未得到评估。

## 9. 未来研究方向

1. **规则生命周期的精细管理**：引入规则置信度评分、定期校验、过期淘汰和冲突消解机制，使记忆不是"只增不改"，而是能自我修正的动态知识库。
2. **主动探测与前瞻防御**：在攻击到来之前主动生成潜在攻击包装并预演归纳，将"从失败中学习"升级为"在失败前预学习"，缩小冷启动暴露窗口。
3. **扩展到更多攻击场景**：多轮对话攻击、越狱 + 工具调用的 agentic 攻击、多模态攻击、非英语语言场景的验证。
4. **记忆检索的语义化升级**：用向量检索替代/补充当前"标签匹配 + LLM打分"的检索方式，支持跨标签的模糊匹配，提高对复合包装的适应性。
5. **细粒度的响应策略**：从三档扩展到连续或分层的策略空间，支持"部分拒绝 + 引导安全替代方案"等更人性化的交互方式。
6. **能力的自进化（而非仅安全的自进化）**：将当前框架从"防御规则积累"扩展到"有益能力积累"（如从成功任务中提取工具使用技巧），实现安全与效用的双重终身学习。
7. **正式的理论分析**：为规则归纳的泛化界、记忆容量与防御性能之间的权衡提供理论刻画，弥补当前实证驱动的不足。

---

## 10. 总体结论与学术定位

本文提出了一种**以持久化规则记忆为核心的测试时自进化防御框架**，在机制上与此前的静态防御和实例级自适应防御形成了清晰的代际区分。通过"方法级标签 + 结构性包装描述 + 拒绝约束"的规则形式，系统能够在单次失败后抽象出可跨实例复用的防御知识，从而在 4 种攻击家族、3 个模型上取得一致的显著防御效果，同时保持良性任务效用几乎不变。

从其学术定位看，本文的价值不在于复杂度的堆砌，而在于**揭示了一个关键的设计原则：安全对齐的持续进化不一定要通过参数更新来实现，外部记忆 + 选择性触发可以成为同等有效的替代路径**。这一原则对黑盒 API 模型尤其有价值，也为后续将"终身学习"理念引入 LLM 安全对齐打开了空间。当然，冷启动暴露、对全新包装的被动响应、以及 LLM 归纳的不确定性，意味着这套框架尚不是防御的终点——它更像是一个**正确的方向上值得深入探索的重要一步**。
