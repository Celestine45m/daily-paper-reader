## 摘要
大型语言模型的快速发展要求具备鲁棒的机器生成文本检测能力。现有范式通常遵循两条相互独立的路径：无训练方法依赖困惑度等全局统计标量，而基于训练的方法利用语义隐藏状态。这两种方法在对抗场景下均表现出根本性的脆弱性。全局标量作为一种有损压缩，会掩盖交错文本中的局部概率突发现象，而纯语义模型则过度拟合特定指纹，仍易受欺骗攻击。为揭示这些缺陷，我们引入了MOSAIC，一个包含16000个样本、覆盖全粒度攻击谱系的综合性对抗基准。为应对这些挑战，我们提出了NeuroStat，一个弥合统计与语义鸿沟的端到端框架。NeuroStat从单一因果语言模型骨干中同时捕获未压缩的词元级概率对数与深层语义隐藏状态。我们通过宏状态残差调制融合这些异构信号，利用全局不确定性指标自适应校准局部卷积特征。正交损失和对比损失进一步确保学习到互补表示。大量实验表明，与现有最先进方法的严重性能退化相比，NeuroStat在MOSAIC上保持了卓越的鲁棒性，为对抗性文本检测树立了新标准。代码和MOSAIC基准可在https://github.com/TencentBAC/NeuroStat获取。

## Abstract
The rapid evolution of large language models necessitates robust machine-generated text detection. Existing paradigms typically follow two isolated tracks. Training-free methods rely on global statistical scalars such as perplexity, while training-based methods utilize semantic hidden states. Both approaches exhibit fundamental vulnerabilities in adversarial scenarios. Global scalars act as lossy compressions that obscure local probabilistic burstiness in interleaved texts, whereas pure semantic models overfit to specific fingerprints and remain susceptible to spoofing. To expose these flaws, we introduce MOSAIC, a comprehensive adversarial benchmark comprising 16000 samples across a full-granularity attack spectrum. To address these challenges, we propose NeuroStat, an end-to-end framework bridging the statistical and semantic gap. NeuroStat captures uncompressed token-level probabilistic logits alongside deep semantic hidden states from a single causal language model backbone. We fuse these heterogeneous signals through Macro-State Residual Modulation, which adaptively calibrates local convolutional features using global uncertainty indicators. Orthogonal and contrastive losses further ensure the learning of complementary representations. Extensive experiments demonstrate that NeuroStat maintains exceptional robustness on MOSAIC compared to the severe degradation of state-of-the-art methods, establishing a new standard for adversarial text detection. Code and the MOSAIC benchmark are available at https://github.com/TencentBAC/NeuroStat.

### 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：大型语言模型的快速发展使得机器生成文本（AIGC）与人类写作的界限日益模糊，由此引发的虚假信息传播、学术不端等风险促使机器生成文本检测（MGTD）成为关键研究前沿。然而，恶意用户很少直接生成整篇文档，而是采用人类-AI交错写作或统计劫持等对抗手段绕过检测器。
- **现有范式缺陷**：
  - **无训练（Training-Free, TF）方法**：依赖困惑度、熵等全局统计标量。这类标量本质上是**有损压缩**，会平滑掉交错文本中局部的概率突发性（burstiness），且容易被高熵指令劫持。
  - **基于训练（Training-Based, TB）方法**：微调编码器以捕捉语义风格指纹。这类方法**过拟合特定生成模型的语义指纹**，易受风格操纵（如同义替换、改写）欺骗。
- **核心洞察**：TF 与 TB 两种范式实际上提供了**正交但互补**的视角——TF 捕捉解码过程的概率机制，TB 捕捉上下文语义。现有方法没有有效融合这两种信号的方案。
- **整体贡献**：论文同时提供了问题诊断（MOSAIC 基准）和解决方案（NeuroStat 框架），建立了对抗性文本检测的新标准。

### 2. 方法论：NeuroStat 框架

**核心思想**：将检测过程解耦为两个正交视角——解码过程的概率机制（TF 分支）与上下文语义伪影（TB 分支），并从未压缩的信号中学习互补表示。

**整体架构**：给定输入序列 x = (x₁, ..., x_T)，通过**单一 CausalLM 骨干**的前向传播，同时获得全词表 logit 矩阵 L ∈ R^{T×|V|} 和最后一层隐藏状态 H ∈ R^{T×d}，分别路由到两个分支。

**2.1 概率轨迹分支（TF）**：
- 提取实际 token 的平移对数概率轨迹 ℓ = (ℓ₁, ..., ℓ_{T−1})，其中 ℓ_t = log softmax(L_t)_{x_{t+1}}。
- 与压缩为标量的传统方法不同，该分支**保留完整的序列结构**，通过分层 1D-CNN 捕捉局部概率异常（人类写作中明显的方差，即局部突发性）。
- 关键创新——**宏状态残差调制（MSRM）**：CNN 缺乏全局上下文意识，因此 MSRM 利用两个宏状态不确定性指标——平均熵 Ē 和平均 log-rank R̄——通过残差门控机制动态校准 CNN 特征：c̃ = c ⊙ (1 + σ(W_g s))。概念上，当全局熵低（AI 生成的高置信度特征）时，MSRM 作为局部异常信号的**自适应放大器**。经验验证显示学习的门控激活与平均熵呈 −0.62 的 Pearson 相关。

**2.2 语义伪影分支（TB）**：
- 使用**可学习的注意力池化**从隐藏状态 H 中聚合信息，动态分配权重给最具语义判别力的 token，并投影得到 TB 表示 z_tb。
- 捕捉 AI 文本的高层风格特征（如重复措辞模式、"delve into" 等固定表达）。

**2.3 训练目标**（三类损失联合优化）：
- **交叉熵损失（L_CE）**：主要分类损失。
- **监督对比损失（L_SupCon）**：在 ℓ2 归一化的融合向量上应用，拉近同类样本、推开异类样本，增强对分布偏移（OOD LLM）的鲁棒性。
- **正交惩罚（L_Orth）**：最小化 TF 与 TB 分支表示之间的平方余弦相似度，强制两个分支张成**正交子空间**，防止特征坍缩和冗余编码。经验数据显示，加入 L_Orth 后分支间均方余弦相似度从 0.358 降至 0.018（接近随机向量的 0.016 下限）。
- 总目标：L = L_CE + λ_SupCon·L_SupCon + λ_Orth·L_Orth。

### 6. 主要结论与发现

- **现有范式在对抗攻击下系统性失效**：TF 方法在统计劫持下 AUROC 跌至约 34.5（Fast-DetectGPT），TB 方法在翻译清洗下表现不佳（ImBD 73.1），在字符/编码攻击下 DetectAnyLLM 退化为近乎随机猜测（52.7）。
- **NeuroStat 实现 SOTA 鲁棒性**：
  - MIRAGE-SIG 下 Qwen3.5-0.8B 在 Generate/Polish/Rewrite 任务上分别达 0.9954/0.9739/0.9665 AUROC；
  - MOSAIC 上 Qwen2-0.5B 总体 AUROC 达 83.4，Qwen3.5-0.8B 的 TPR@5% 达 58.1（较前 SOTA 提升 17.6 个百分点）。
- **架构不对称性带来天然防御优势**：攻击者篡改语义必然暴露概率异常（TF 分支可捕捉），篡改统计则破坏语义连贯性（TB 分支可捕捉），形成结构性不对称攻击面。
- **正交正则化有效防止双分支冗余**：分支间余弦相似度从 0.358 降至 0.018，接近随机基线。
- **MSRM 的残差门控设计优于纯乘法门控**：残差形式（乘子 ≥ 1）保证局部异常特征永远不会被抑制为零，而纯门控在攻击者抬高全局置信度时可能抹除局部证据。
- **校准质量显著更优**：NeuroStat 的 ECE 明显低于 DetectAnyLLM，置信度更可靠。

### 7. 优点

- **范式创新**：首次实现 TF 与 TB 范式的端到端联合融合，用未压缩的词元级概率轨迹取代传统有损全局标量，填补了两大范式的鸿沟。
- **MSRM 设计精巧且可解释**：全局不确定性指标自适应调制局部特征，并通过 Pearson 相关分析验证了其行为符合设计直觉；附录 D 通过 7 种融合机制对比证明增益来自残差公式而非参数增加。
- **基准构建严谨**：MOSAIC 的四阶段净化（SimHash+LSH 去重、6 维质量评分）、长度分层模型分配、质量审计（人工 kappa、BERTScore、GPT-4o 评分）体现了方法论上的严谨性；36 种子攻击的类别间 JS 散度验证（0.38 vs. 0.07）确保攻击之间的语言学差异性。
- **公平性考量**：所有 TB 基线在相同的 500 对训练分割上重新训练；训练样本敏感性分析明确了性能-数据量关系；消融实验排除了"增加的微调容量"这一混淆变量（附录 D）。
- **工程完备性**：代码、基准、详细超参数、计算成本、闭源部署方案均有说明，可复现性强。

### 8. 不足与局限

- **语言与领域局限**：实验仅限于英语文本，覆盖新闻、创意写作、生物医学摘要等领域；对低资源语言、代码生成、法律文档等专业领域的有效性未验证。
- **对数概率黑盒依赖**：概率轨迹分支需要 CausalLM 暴露完整的词元级对数概率。对于不提供此类接口的闭源 API，必须依赖开源替代模型，存在 3–7 个 AUROC 点的性能差距（附录 F），且这一差距在更极端的闭源模型上可能被放大。
- **计算开销**：全词表 logit 矩阵的存储和处理带来约 10% 的额外延迟和内存（相对 DetectAnyLLM），在大规模部署场景中可能受限。
- **过度鲁棒性可能隐含侵入性**：检测器在极端攻击下仍能保持较高准确率，但可能伴随更高的误报风险——非英语母语者的写作模式可能触发误判，论文虽在伦理声明中强调"辅助信号而非最终证据"，但未提供实际误报率分析。
- **数据量限制**：MOSAIC 基准基于 16,000 对数据，按 36 种子攻击 × 6 模型分配后，每种子攻击平均仅约 444 对，统计稳健性可能受限。
- **攻击类别内部粒度不均**：从 Tab. 3 可见，Domain/Format 类攻击对多数方法都较易（DetectAnyLLM 达 95.1），而 Character/Encoding 类是最难的；不同类别之间的难度差异未做归一化分析。
