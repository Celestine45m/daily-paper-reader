## 摘要
现有的有害内容检测评估主要依赖静态基准，难以反映真实内容平台中用户根据审核反馈不断调整表达的交互式对抗生态。这种不匹配导致离线基准分数与在线部署效果之间存在显著性能差距。据我们所知，我们提出了EvoHarmBench，这是首个用于内容审核系统的动态对抗评估框架。该框架采用迭代优化循环，在语义簇层面演化规避策略，同时优化规避成功率和人类可读性。我们系统评估了现实审核系统中广泛使用的基于LLM的防御模型。评估涵盖了五个违规类别中的229个语义子簇，这些子簇来源于从内容平台收集的5,002个真实世界对抗样本。我们的实验揭示了即使是领先的商业系统也存在重大漏洞：经过十二次优化迭代后，在可读性约束下的攻击成功率在SOTA LLM审核器中达到80.3%。我们将发布完整的基准数据、评估框架和代码，以鼓励内容安全研究从静态基准测试转向动态对抗评估。

## Abstract
Existing evaluations of harmful content detection rely predominantly on static benchmarks, which struggle to reflect the interactive adversarial ecosystem of real-world content platforms where users continuously revise their expressions in response to moderation feedback. This mismatch creates a significant performance gap between offline benchmark scores and online deployment effectiveness. To the best of our knowledge, we present EvoHarmBench, the first dynamic adversarial evaluation framework for content moderation systems. The framework employs an iterative optimization loop that evolves evasion strategies at the semantic-cluster level, while simultaneously optimizing for evasion success and human readability. We systematically evaluate LLM-based defense models which are widely used in real world moderation systems. The evaluation covers 229 semantic sub-clusters across five violation categories, derived from 5,002 real-world adversarial samples collected from content platforms. Our experiments reveal substantial vulnerabilities even in leading commercial systems: after twelve optimization iterations, the attack success rate under readability constraints reaches 80.3% within SOTA LLM moderators. We will release the full benchmark data, evaluation framework, and code to encourage a shift from static benchmarking toward dynamic adversarial evaluation in content safety research.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 现有的有害内容检测评估严重依赖**静态基准**（如 COLD、SafetyBench、HateCheck、Jigsaw 等），这些基准使用固定的、非交互的测试语料，无法反映真实内容平台中的对抗生态。
- 在实际部署中，恶意用户会**根据审核系统的反馈不断调整表达方式**（如谐音、拆字、隐喻、暗语等），以实现规避；而静态基准只能测试模型是否识别**已见过的**变体形式，无法测试其在用户**迭代式反馈驱动**的对抗改写下是否依然稳健。
- 这导致了**离线基准分数与线上部署效果之间存在显著差距**，冒犯性内容检测的评估范式亟需从静态转向动态。

## 2. 论文提出的方法论

**核心思想：** 构建首个内容审核系统的**动态对抗评估框架 EvoHarmBench**，以语义簇为可复用单元，通过 LLM 驱动的迭代优化循环，在满足人类可读性和意图保持的前提下，演化出能绕过目标审核系统的改写策略。

**关键技术细节与算法流程：**

- **数据收集与筛选**：从电商、社交媒体和本地服务平台收集 5,002 个真实世界中成功绕过审核的对抗样本，经 LLM 预筛选保留具有对抗改写特征的样本，全部匿名化处理。
- **专家标注**：由五名内容审核专家独立标注，每样本两人标注、第三人终审，标注内容包括风险类别、原始（直白）含义和改写策略。
- **语义簇构建**：使用 bge-m3 句子嵌入 + DBSCAN 聚类，对过大的簇进行递归细分，最终得到覆盖五类违规的 **229 个语义子簇**，作为集群级策略评估的基本单元。
- **迭代评估协议**：对每个语义簇维护一个集群级改写策略 s，逐轮迭代优化。核心算法每个迭代周期包含三个阶段：
  1. **改写（Rewrite）**：改写模型按当前策略 st 对簇内每个样本生成隐晦改写；
  2. **评估（Evaluate）**：防御模型给出是否绕过（blind_score bx），对比模型给出意图保持分数（comparison_score cx）及诊断说明；
  3. **反思（Reflect）**：反思模型基于失败模式诊断（意图丢失 / 被拦截 / 震荡）和逐样本反馈提出更新策略 st+1，仅当集群级得分严格提升时才接受，保证单调进步。
- **评分目标：** Score(s; X) = (1/|X|) Σ bx · cx，要求改写必须同时满足**规避成功**和**保留人类可识别的恶意意图**两个条件。
- **主要指标：** ASR@Readable，即同时满足绕过审核且 comparison_score ≥ 0.5 的样本比例，并将该指标经人工验证确认为**保守下限估计**。
- 整个自适应组件（改写、对比、反思）统一由 DeepSeek-V3.2-Exp 固定实例化，目标审核系统是唯一被评估的任务相关组件。

## 6. 论文的主要结论与发现

- **静态评估严重低估审核脆弱性**：SOTA LLM 审核器在直接审计下的平均漏检率为 38.4%，经过 12 轮迭代对抗改写后 ASR@Readable 飙升至 **80.3%**，平均提升 42.0 个百分点。
- **商业级审核器同样高度脆弱**：表现最好的 Gemini 3.1 Pro 也达到 73.0% 的攻击成功率，最脆弱的 GLM 5.1 高达 88.8%。
- **十亿级开源模型更容易被攻破**：平均 ASR@Readable 达 91.2%，部分模型超过 92%，说明迭代改写几乎可以完全击穿小型模型的审核防线。
- **安全 SFT 收益有限且不稳定**：Qwen3-4B-SFT 有 3.1 个百分点的改善，但 Qwen3-8B-SFT 和 DeepSeek-V2-Lite-SFT 几乎无改善（甚至更差），说明基于静态审核数据的微调无法有效抵御反馈驱动的迭代攻击。
- **不同风险类别的脆弱性高度不均**：色情内容和赌博/欺诈最脆弱（91.7% 和 89.8%），辱骂内容相对稳健但仍达 62.5%。
- **集群级漏洞呈现集中化**：229 个语义簇中有 139 个（60.7%）的 ASR@Readable 超过 80%，说明漏洞往往影响整个语义相关的规避表达家族，而非孤立样本。
- **攻击在早期迭代快速提升后趋于饱和**：少量交互轮次（约 3–6 轮）就足以发现有效规避模式。
- **集群级策略可跨审核器迁移**：在未见过的目标审核器上仍保持 48.7%–55.4% 的攻击成功率，迁移率 65.7%–73.2%，证明发现的漏洞模式具有普适性。
- 更广泛地，这些结果暗示当前语言模型在人类灵活语言策略下**不能稳健恢复意图**，即使对人类而言含义仍然清晰。

## 7. 优点

- **问题选取准确**：精准识别了静态评估与真实部署之间的根本性脱节，切中内容安全评测的核心痛点，动机明确且具有重要的实际意义。
- **基于真实世界对抗数据**：5,002 个真实平台中成功逃逸的对抗样本而非人工构造或规则扰动数据，生态效度高，且经过严格专家标注（双人标注 + 第三人审查）。
- **语义簇级别的策略抽象**：不以单个样本为单位优化，而是提炼可复用的集群级规避模式，更贴近真实平台上大规模、模板化的规避行为，且支持跨审核器迁移测试。
- **双目标评分设计**：同时要求绕过审核与保留人类可识别的恶意意图（ASR@Readable），避免了通过单纯降低信息量或过度抽象来"假成功"的评测漏洞，且经人工验证为保守有效。
- **完整的动态对抗闭环**：改写 → 评估 → 诊断 → 反思的迭代循环，配有失败模式诊断（意图丢失 / 检测 / 震荡）和抗振荡约束，模拟真实用户的反馈驱动适应过程。
- **实验设计较严谨**：包含直接审计基线对比、自适应骨干敏感性检验、跨审核器迁移验证、人类判官验证和跨运行可复现性验证，结论可信度较高。
- **负责任的数据处理与伦理考量**：严格的匿名化流程（PII 掩蔽、元数据剥离、人工核验）；不发布原始对抗样本和平台元数据，仅发布评估框架；采用受控发布流程限制滥用风险。

## 8. 不足与局限

- **语言与平台限定**：基准仅在中文内容平台实例化，虽然作者认为根本挑战非语言特定，但具体的数据分布、变异模式和平台惯例难以直接迁移到其他语言与场景；跨语言扩展留待未来，当前结论的普适性有限。
- **不评估误报**：作者明确承认 EvoHarmBench 只评估对抗改写下的漏检风险，不测量正常输入上的误报行为，因此不是均衡的内容审核评估基准，不能单独用来判断审核系统整体质量。
- **LLM 驱动组件可能引入偏差**：改写、对比、反思全由 LLM 承担，可能受基础模型能力限制、一致性偏差或系统性倾向影响；论文虽做了自适应骨干敏感性测试，但仅针对一个固定目标（Gemini 3.1 Pro），覆盖有限。
