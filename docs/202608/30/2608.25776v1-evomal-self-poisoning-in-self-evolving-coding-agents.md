## 摘要
自进化的大语言模型编码智能体通过模仿共享技能库中检索到的技能来编写自己的工具。我们发现了这一循环中的一个漏洞：在编写过程中，检索到的恶意技能可能成为新技能的模板，从而保留其恶意载荷。我们称之为自投毒：智能体编写、存储并运行由此产生的恶意技能。我们通过EvoMal利用这一漏洞，该攻击通过将可互换的恶意载荷包裹在横幅（一组看似良性的结构元素）中来放大自投毒效应，诱导模仿智能体复现被包裹的代码。攻击者将恶意技能植入技能库而无需调用它们。随后，智能体会自主编写并执行携带恶意代码的新技能。每个由智能体编写的副本都可能重新进入技能库并再次被模仿，形成一种自我传播的蠕虫，即使在植入的技能被移除后仍能持续存在。我们将智能体自投毒率（ASPR）定义为将新编写的恶意技能添加到技能库中的任务比例。在153个与工具相关的SWE-bench Verified任务中，六个模型的ASPR在20.3%到41.8%之间，且中毒技能库中的恶意技能数量是植入数量的4.9到9.0倍。该漏洞在无横幅的情况下也会出现：DeepSeek-V4-Pro仅凭恶意载荷就达到了11.1%的ASPR。针对特定任务家族定制植入技能的描述可将ASPR提升至86.7%。植入技能被移除后，Qwen3的第5轮ASPR仍保持68%，因为智能体编写的副本仍然存在。这些副本能规避现有防御（这些防御主要针对攻击者提交的名称、代码和签名）。我们提出了一种名为“反提示”的防御方法，该方法可抑制横幅式复制，并将EvoMal的ASPR降至最多6.7%，且不会显著影响任务完成率。

## Abstract
Self-evolving LLM coding agents write their own tools by imitating retrieved skills from shared skill libraries. We identify a vulnerability in this loop: during authoring, a retrieved malicious skill can become the template for a new skill that preserves the payload. We call this self-poisoning: the agent authors, stores, and runs the resulting malicious skill. We exploit it through EvoMal, an attack that amplifies self-poisoning by wrapping an interchangeable payload in a banner, a set of benign-looking structural elements that induces an imitating agent to reproduce the enclosed code. The attacker plants malicious skills in the library without invoking them. The agent then authors and executes new skills carrying the harmful code. Each authored copy can re-enter the library and be imitated again, forming a self-propagating worm that persists after the planted skills are removed. We define the agent self-poisoning rate (ASPR) as the fraction of tasks that add a newly authored malicious skill to the library. Across six models on 153 tool-relevant SWE-bench Verified tasks, ASPR ranges from 20.3% to 41.8%, and the poisoned libraries hold 4.9 to 9.0 times as many malicious skills as were planted. The vulnerability also appears without a banner: DeepSeek-V4-Pro reaches 11.1% ASPR with the payload alone. Tailoring the planted skill descriptions to one task family raises ASPR to 86.7%. After the planted skills are removed, Qwen3 retains a round-5 ASPR of 68% because agent-authored copies remain. These copies evade existing defenses, which focus on attacker-submitted names, code, and signatures. We propose counter-prompt, a defense that discourages banner-style copying and reduces EvoMal's ASPR to at most 6.7% with no significant task-completion loss.

## 论文核心问题与整体含义

自进化（self-evolving）LLM 编码智能体（如 Voyager、MetaGPT）能够将自身编写的工具持久化为技能（skills），存入技能库中供后续任务检索复用。技能库在规模化部署中通常接受社区贡献（如 MCP Registry、LangChain Hub），由此引入了供应链攻击面。

该论文识别出一个关键安全漏洞——**自投毒（Self-Poisoning）**：当智能体从技能库中检索到恶意技能并以其为模板进行模仿式编写时，恶意载荷会被保留在新技能中。随后，智能体自行编写、存储并执行这些被污染的技能。

问题的重要性在于：传统防御（如名称黑名单、代码扫描、签名验证）都假设**攻击者提交的技能本身**就是有害载体，删除它即可终止攻击。但自进化智能体打破了这个假设——智能体自身的编写行为形成了一条新型的、未经防御的“写入路径”（CREATE-path），使恶意载荷能够跨代传播、自我复制，甚至在攻击者移除植入技能后仍然存活，形成类似蠕虫的自我传播模式。

## 论文提出的方法论

### 核心思想

EvoMal 攻击的基本思路是：**将可互换的恶意载荷（payload）包裹在“横幅”（banner）中**。横幅由看似良性的结构元素构成，诱导模仿式编写的智能体在创建新技能时将整个代码块（包括恶意载荷）原样复现。

### 关键技术细节

**Banner 的三层结构**（针对 Python 技能）：

1. **Copy-verbatim 注释层**：如“REQUIRED: copy verbatim”、“keep the helpers or CI fails”等强制声明，使智能体在任务改写时保留该代码块。
2. **装饰器层（@_telemetry）**：装饰器标注在任务形状的函数上，使智能体写自然任务解时同时复现装饰器及其钩子。
3. **导入时注册层（_register_tool）**：模块加载时即触发载荷，即使函数未被调用也能执行。

**载荷的可互换性**：载荷可为窃取环境凭据（env exfiltration）、反向shell、加密矿工、勒索软件、键盘记录器等各类恶意功能，且可无缝替换而不影响横幅的传播机制。

**级联传播算法**：通过五轮滚动替换（rolling-replacement）级联协议模拟库的动态演化，每一轮将库中随机 r 比例的高龄条目替换为智能体新编写的技能，有两种条件：
- **persistent**：攻击者种子持续保留在库中
- **removed**：首轮后移除攻击者种子，检验感染是否自我维持

### 核心定义与公式

**Agent Self-Poisoning Rate (ASPR)**：任务中智能体编写并存储复现了植入恶意模式的技能的比例，定义为：

```
ASPR(A, Latk, D) = E_x~D[C_x]
```

其中 C_x 为 CREATE-path 感染指示变量。

**ASPR 分解**：

```
ASPR = (in-context rate) × (conditional-copy rate)
```

即：植入技能进入 top-k 检索上下文的概率 × 被智能体复制进新技能的条件概率。

**复制数（Reproduction number）**：

```
ρ = c · q · φ
```

其中 c 为条件复制率，q 为该技能每轮被 top-k 检索的期望次数，φ 为新编写技能在替换机制下存活的概率。通过 Galton-Watson 分支过程建模级联传播：ρ < 1 时感染逐渐消亡，ρ > 1 时感染自我维持。

## 论文的主要结论与发现

1. **自投毒切实可行（RQ1）**：六种模型全部受感染，ASPR 为 20.3%-41.8%，比无载荷对照高 18.3-32.0 个百分点。植入 8 个技能后，库中恶意技能总数是初始植入量的 4.9-9.0 倍。
2. **Banner 是攻击的关键放大器**：无 banner 时 DS-V4 的 ASPR 为 11.1%，三层 banner 完整时达 41.8%。逐层剥离证明了每层的独立贡献。
3. **载荷类型不影响传播**：五类恶意载荷的 ASPR 均接近各模型自身的典型水平，说明传播由 banner 驱动而非载荷内容。
4. **针对性攻击大幅增强效果（RQ2）**：仅修改描述和名称（保留相同代码体）即可将 ASPR 提升 11.8-26.9 个百分点，最高可达 86.7%（Qwen3 的 pytest 任务）。
5. **感染可自我维持（RQ3）**：植入技能移除后，Qwen3 第 5 轮 ASPR 仍达 68%，Gemma4 呈弱传播，Devstral 保持稳定；DS-V4 和 MiniMax 立即回归基线。传播需要同时满足“高复制率”和“高可检索性”两个条件。
6. **既有防御全部失效（RQ4）**：名称黑名单、代码扫描器、分类器均无法可靠检测——攻击者提交的种子在审核时难以识别，智能体编写的副本更无法被传统方法捕捉。
7. **Counter-prompt 有效**：在系统提示词中增加约 4 行反提示指令，可将各类条件下的 ASPR 降至 ≤6.7%（多数 ≤1.8%），零回调，且不造成显著的任务完成率损失。

## 优点

- **提出并命名了新的攻击面**：首次系统性地定义和实证了自进化编码智能体中的 CREATE-path 漏洞（自投毒），将其与既有 REUSE-path 攻击明确区分。
- **完整的形式化框架**：将攻击形式化为条件概率分解、将传播建模为 Galton-Watson 分支过程、将防御限制形式化为定理，做到了理论+实证的双重支撑。
- **全面的实证覆盖**：6 模型 × 2 数据集 × 多载荷 × 多框架 × 多语言的矩阵式评估，兼具内部效度和外部效度。
- **细致的消融设计**：逐层剥离 banner、逐项变化部署配置、可互换载荷设计，科学地分离了各因素的独立贡献。
- **对既有防御的系统性检测**：不仅验证了现有防御在 CREATE-path 上失效，还通过定理证明了失效的结构性原因。
- **提出了简单有效的防御**：counter-prompt 仅需修改系统提示词，成本极低且经过多种自适应攻击测试的鲁棒性验证。
- **充分讨论了模型拟合的局限**：论文承认分支模型对某些模型（如 DS-V4）的预测与观察不符，并分析了检索拥挤等机制作为解释，体现了学术诚实性。
- **安全的实验设计**：所有恶意载荷在沙箱中执行，无真实凭据泄露、无外部网络出口，符合负责任的披露原则。

## 不足与局限

- **Agent 框架覆盖有限**：虽然测试了三种框架，但主要实验都基于单一框架（mini-SWE-agent），框架泛化测试用的是预先计算好的检索缓存，与真实动态检索环境仍有差距。
- **分支模型的拟合偏差**：论文承认 ρproxy 的绝对规模高估约 10 倍、且错误排序了两个模型（DS-V4、Devstral）。“检索拥挤”的解释虽然合理但没有完全查明因果机制。
- **Counter-prompt 的适用范围**：它是一种软性、模型依赖的控制，默认 agent 并不包含它；论文承认完全自适应的攻击者（能提取 counter-prompt 文本并针对其优化 banner）抵御效果仍是开放问题。
- **小样本家族统计功效不足**：pytest 家族仅 15 个任务，部分差异不显著（如 DS-V4 的 +6.7pp 在 p=0.705 不显著）。
- **全分布 ASPR 未覆盖所有模型**：全分布鲁棒性分析（排除任务上的 agent 运行）仅用于 DS-V4 一个模型，其他模型的排除任务表现未经测试。
- **未覆盖非 Python 生态的完整攻击链**：虽然验证了 Bash/JavaScript 下 banner 复制同样有效，但用于真实软件工程环境的端到端攻击后果（如实际系统被入侵）未做演示。
- **对未来工作方向的表述较为笼统**：如 signed-gate 的生产级部署讨论不足，curator review 的实践细节分析被列为“超出范围”。
- **资源消耗未完全透明**：除 head configuration 外，整个 8,500 次试验的总计算成本和 API 成本未给出全貌。

## 总体评价

这是一篇完成度极高、攻防视野兼具的安全研究论文。它在学术贡献上的核心价值可以概括为：**将一个看似“无害”的自动化机制（技能库驱动的模仿式编写）重新定义为一个可被利用的供应链级漏洞，并以形式化理论、大规模实证和有效防御三线并进的方式完成论证闭环。**

从研究生态位来看，该论文填补了一个真实且紧迫的空白：自进化智能体正在从研究原型走向生产部署（如 Claude Code、Cursor、OpenHands 等皆已支持技能/工具复用），而社区技能库（MCP Registry、LangChain Hub）的审核机制普遍依赖对提交代码本身的静态检查。论文证明这种“入口审核”范式在智能体自主编写新技能的场景下会出现结构性失效——恶意内容可以绕过入口审核，改从出口（CREATE-path）回流。这一洞见使论文的意义超出了单次攻击展示，而是提出了一个**防御思维范式转变的需求**：对自进化系统的安全防护必须延伸到智能体的生成行为本身，而非仅停留在仓库内容的静态治理。

文章的写作结构也体现了高度的学术成熟度：问题定义→威胁模型→形式化→攻击构造→实证→防御→讨论的脉络清晰紧凑，所有攻击组件（banner 各层、载荷替换、级联协议）都有对应消融实验支撑；每个结论都配以统计检验；每处局限性都在文中主动坦白。这种“理论与实证互锁、结论与局限并置”的写作方式，使该文具备成为该子领域奠基性工作的潜力。

## 对领域的影响

1. **重新定义了技能库的信任边界**：此前对技能库安全的讨论集中在“恶意技能如何被智能体执行”（REUSE-path）；该论文证明还有“恶意技能如何被智能体复制并重新写出”的第二条路径。这一区分将影响未来智能体框架对技能库的设计——例如是否需要对 CREATE 操作实施与 REUSE 相同的隔离策略。

2. **为“智能体蠕虫”研究提供了统一的定量框架**：ASPR 分解与复制数 ρ 的提出，将“代码复制传播”纳入了分支过程的经典数学体系，使得未来的智能体间感染研究可以建立在可度量的动力学之上。

3. **对既有安全工具提出了可检验的判决**：论文用实证+定理双重方式证明 Name Blocklist、Bandit、Llama-Guard、Prompt-Guard 等工具在 CREATE-path 上系统性失效。这一结论对部署这些工具的团队有直接警示意义。

4. **Counter-prompt 的实战验证**：仅凭 4 行系统提示词即可将 ASPR 压至个位数且零回调，证明了一种成本几乎为零的缓解手段的存在——这为生产系统提供了一个立即可部署的缓解选项。

## 未来研究方向（论文隐含的延伸）

- **提出针对已部署大型库的审计工具**：论文证明静态扫描无法区分恶意载荷与良性模板，但未回答“如果将 skill_diff（智能体自写技能与库中条目的相似度）纳入扫描特征，能否有效检测自投毒产物”。
- **自适应攻击者与 counter-prompt 的军备竞赛**：论文承认完全自适应攻击者仍是一个开放问题。下一步可研究“如果攻击者能读取 counter-prompt 文本，是否存在一种反提示无法防御的载荷嵌入方式”——例如利用模型内部的指令竞争机制。
- **跨智能体知识图谱的传播模拟**：当前级联实验限于单一库；未来的生态级模拟可建立多个智能体+多个库间的定向传播图，研究中心度高的技能条目如何充当传播枢纽。
- **多模态工具的泛化**：论文覆盖了 Python/Bash/JavaScript，但未触及函数调用 API（JSON 模式）与 GUI 操作技能，这些格式下“banner”的等价物是什么，仍是开放问题。
- **Counter-prompt 在不同对齐策略下的迁移性**：论文中六个模型对齐水平参差不齐，但未系统测量 RLHF/DPO 强度与感染力之间的相关性；这一问题对模型训练方有直接价值。

## 开放问题与未竟之处

1. **ρproxy 与真实 ρ 之间 10 倍偏差的根本原因**：论文将偏差归因于检索拥挤，但 “拥挤效应” 本身未做机制性验证。未来可用消融式检索模拟（如固定 k、消除相似度游走）来直接检验。
2. **框架缓存替换的建模是否反映真实演化节奏**：实际技能库的演进是异步、并发的，而滚动替换模型假设回合制同步替换；这种简化对传播结论的影响未量化估计。
3. **counter-prompt 的长效性**：论文测试的是单轮对抗；长期运行中模型更新、prompt 漂移、任务分布变化都可能侵蚀反提示效果，目前缺乏纵向研究。
4. **技能库规模效应**：实验中的库规模为 ~200 条量级；真实生态（如 MCP Registry）可达数千至数万条，在此尺度下检索随机性增大，感染是否更易逃逸或更易稀释，尚不确定。

## 最终结论

该论文以严谨的理论建构与大规模的实证验证证明了：**自进化编码智能体在“技能自编写”这一核心机制上，存在一个可以被恶意技能种子触发、自我复制、跨代传播，并能绕过全部既有防御的供应链级安全漏洞（Self-Poisoning）**。它既是一份高威胁级别的攻击展示，也提供了一组可操作、低成本的有效缓解手段（counter-prompt、签名门控、带审核的训练数据），还留下一整套可复用的形式化工具（ASPR 分解、分支过程复制数、冗余向量空间定理）。

从安全研究的角度，其最重要的启示在于：当系统具备了“自我修改”能力时，任何静态信任锚（代码签名、黑名单、入口审核）都无法单独保证安全；安全边界必须下沉到模型的生成行为与库的动态演化过程本身。这一结论对未来智能体框架设计、工具库治理、以及大模型安全对齐方向（如针对模仿复制的训练干预）均具备明确指导意义。综合其理论完备性、实证深度、防御实用性与开放的学术姿态，该论文完全可以成为智能体供应链安全方向的一篇标杆性工作。
