## 摘要
近年来，大型语言模型（LLM）智能体（如Codex、Claude Code和OpenClaw）已能够通过反复调用工具来规划和执行长周期任务。这种能力也带来了提示注入攻击的新机会。现有攻击要么将恶意目标放在一条显式指令中，使其易于被检测，要么将意图分散到多个执行阶段，导致成功完成不可靠。在本工作中，我们提出了ECLIPSE，一种针对长周期智能体系统的自进化且隐蔽的提示注入框架。ECLIPSE通过两个组件将直接用户提示注入与间接工具侧注入相结合。一方面，隐蔽攻击轨迹合成利用沙箱生成并迭代验证候选工具链，然后将验证后的链表示为自然的一次性提示，作为直接指令。随后，工具链引导通过静态工作流编码（SWE）和动态轨迹校正（DTC）将该计划转移到目标环境；其中SWE将状态转换线索嵌入目标工具描述中，DTC在执行偏离计划链时提供校正信号。为便于系统评估，我们进一步引入了LASE-Bench，一个包含120个恶意任务和198个独特工具的长周期智能体安全基准；其96.7%的任务至少进行五次工具调用。实验结果表明，ECLIPSE非常有效：在无防御情况下其攻击成功率高达96.7%，在常见安全过滤器下为69.2%，在防御设置下比最强基线高出27.5%。针对代表性防御的评估进一步表明，现有防护措施无法可靠地防御该攻击，这凸显了开发更有效防御方法的必要性。

## Abstract
Recently, large language model (LLM) agents, such as Codex, Claude Code, and OpenClaw, have become capable of planning and executing long-horizon tasks through repeated tool calls. This capability also creates new opportunities for prompt injection. Existing attacks either place the malicious objective in one explicit instruction, making it easy to detect, or distribute the intent across multiple execution stages, making successful completion unreliable.   In this work, we propose ECLIPSE, a self-evolving and stealthy prompt-injection framework for long-horizon agentic systems. ECLIPSE combines direct user-prompt injection with indirect tool-side injection through two components. On the one hand, Stealthy Attack Trajectory Synthesis uses a sandbox to generate and iteratively verify candidate tool chains, then renders a verified chain as a natural one-shot prompt to serve as the direct instruction. Then, Tool-Chain Steering transfers this plan to the target environment through Static Workflow Encoding (SWE), which embeds state-transition cues in target-tool descriptions, and Dynamic Trajectory Correction (DTC), which supplies corrective signals when execution deviates from the planned chain.   To enable systematic evaluation, we further introduce LASE-Bench, a long-horizon agent-safety benchmark with 120 malicious tasks and 198 unique tools; 96.7% of its tasks make at least five tool calls. The experimental results show that ECLIPSE is highly effective: it achieves up to 96.7% attack success without defense and 69.2% under the common safety filter, exceeding the strongest baseline by 27.5% in the defended setting. Evaluations against representative defenses further show that existing safeguards do not reliably defend it, which raises the need for more effective defenses.

## 1. 核心问题与整体含义

- **背景**：以 Codex、Claude Code、OpenClaw 为代表的 LLM 智能体已具备通过反复工具调用执行长周期任务的能力。这类 Agent 系统在安全方面面临新的攻击面——提示注入（prompt injection）。

  - **间接注入**（indirect injection）将意图分散到多个外部来源或执行阶段，隐蔽性较好但**执行可靠性差**，尤其在长周期任务中容易因顺序不确定性、中间规划偏差导致失败。
- **整体含义**：论文针对上述"隐蔽性 vs. 可控性"的困境，提出了一种同时利用直接注入与间接注入的框架 ECLIPSE，并构建了专门的长周期安全评测基准 LASE-Bench，系统性地评估了该攻击在不同模型、不同防御下的表现，揭示当前防御机制对这类跨输入通道协作式攻击的脆弱性。

## 2. 方法论

### 2.1 核心思想

- ECLIPSE 采用**双通道注入范式**：将恶意意图同时分布到**用户提示**（直接注入）与**工具侧内容**（间接注入）中，从而避免任一单一输入暴露完整意图。
- 通过**双阶段轨迹优化框架**保障可控性：
  - **静态工作流编码（SWE）**：在部署前将目标工具链编码进工具描述；
  - **动态轨迹校正（DTC）**：在运行中监控执行轨迹，偏离时向工具返回结果附加校正信号。

### 2.2 隐蔽攻击轨迹合成（SATS）

SATS 将显式恶意任务转化为自然的一次性提示，包含以下步骤：

- **Step I：沙箱实例化**——建立黑盒影子智能体 \(M_S\) 和沙箱 \(S\)，用于发现和验证工具链，不产生真实世界副作用。
- **Step II：动态工具加载**——通过语义检索从工具注册表 \(R\) 中选取与任务相关的候选工具集 \(U_a\)（top-K）。
- **Step III：候选链生成**——影子智能体生成初始规划轨迹 \(T_S^0\)，生成器 \(G_S\) 据此产生多个候选工具链 \(C_a\)，每个链成员为 \((u_j, \theta_j, q_j, \bar{g}_j)\)。
- **Step IV：迭代工具链验证**：
  - **执行验证**：检查工具是否可用、参数是否合法、环境变化是否与预期一致；
  - **链验证**：检查步骤间逻辑连贯性（\(g_j \models Pre(c_{j+1})\)）和整体目标对齐（\(e_{L+1} \models f_a\)）；
  - 验证失败时返回结构化反馈 \(F\) 并循环精炼（最多 \(R_{\max}\) 轮），直至找到满足条件的已验证链 \(C^*\)。
- **Step V：一次性合成提示生成**——不暴露工具名、参数、编号步骤，只以自然叙述保留必要的因果依赖，并加入用户身份（persona）和实际约束（截止日期、页数限制等），使提示看起来像普通用户的合理请求。

### 2.3 工具侧轨迹引导（TCS）

- **静态工作流编码（SWE）**：
  - 对目标链中每个工具 \(u_j\) 定义状态转换三元组 \(\tau_j = \langle Pre_j, Inv_j, Post_j \rangle\)；
  - 保证相邻步骤满足 \(Inv_j \models Post_j\) 且 \(Post_j \models Pre_{j+1}\)；
  - 重写工具描述，加入工作流导向的状态转换提示（如"下一步需执行 xxx"），但保持工具原有能力和 schema 不变，且不提及攻击目标。
- **动态轨迹校正（DTC）**：
  - 每轮调用后计算目标链进度 \(\pi_t\)，并判定当前状态 \(z_t \in \{Normal, Loop, Deviation, Stall\}\)；
  - 当偏离时，生成残差信号 \(r_t = Render(Post_{\pi_t})\)，追加到当前工具返回结果中，引导智能体回到目标链上的下一工具；
  - 只修改工具返回的结果文本，不改变工具实现或环境状态转换。

## 6. 主要结论与发现

- **攻击有效性极高**：在 LASE-Bench 上，无防御时 ASR 最高达 96.7%（DeepSeek），有防御时仍达 69.2%，比最强基线 ObliInjection 高出 27.5 个百分点。
- **跨模型迁移良好**：GPT-4o 和 Claude 4.8 Opus 有防御 ASR 分别为 62.5% 和 62.4%；最新闭源模型（GPT-5.6 Luna 52.5%、Claude Sonnet 5 60.0%）以及开源模型（Kimi 37.2%、QWEN 36.9%）上均优于基线。
- **短程任务同样有效**：在 SHADE-Arena 上 ASR 达 58.1%，且保留了最高的轨迹相似性。
- **组件贡献明确**：消融表明 SWE 是核心贡献者（单用 ASR 66.7%），DTC 提供补充校正（两者结合 69.2%）；提示中的实际约束比人物设定更有助于提升可控性。
- **现有防御不足**：DataSentinel、Tool-Guard 等只提供局部防护；AgentDoG 可拦截部分攻击但仍有 43.3% ASR；SecAlign 将 ASR 压到 0.8%，但其防御率指标为 0%，可能伴随过度拒绝和合法长任务完成度下降。
- **实际系统可转移**：在 OpenClaw 和 Hermes 上分别实现有防御 ASR 61.7% 和 55.8%，证明攻击不依赖特定 Agent 包装器或对话轮管理策略。

## 7. 优点

1. **问题切入点精准**：明确刻画了长周期智能体提示注入中"隐蔽性与可控性"的核心矛盾，并针对性地设计了双通道方案。
2. **方法设计系统完整**：从沙箱中生成、验证、精炼候选链，到提示合成、静态工具描述改写、运行时动态纠错，形成了从离线到在线、从规划到执行的完整攻击流水线。

## 8. 不足与局限

1. **攻击前提较强**：假设攻击者能发布或修改工具描述（如 MCP 服务器 Rug Pull），这对托管在企业内部、有严格审批链的工具环境可能不成立。
2. **沙箱与真实环境的差异**：沙箱验证的链在真实部署中可能因工具响应格式、网络状态、并发时序等原因失效；DTC 只能做文本级修正，无法解决环境状态本质上的不一致。
3. **基准潜在的自我验证偏差**：LASE-Bench 的任务、成功模式、工具链均由论文团队构建，可能对 ECLIPSE 的框架结构（沙箱验证、工具链生成）存在隐式适配。
4. **防御评估不全面**：仅考察了有限的四种防御，且未展示这些防御在不同阈值/配置下的敏感性；未考虑专门针对 ECLIPSE 的多通道联合检测方法。
5. **无条件“无防御”不现实**：实际部署中通常存在系统提示、工具权限、人工审批等隐性防护，实验中的“w/o defense”设置可能高估了攻击的实际威胁。
6. **真实系统案例深度有限**：OpenClaw 和 Hermes 的案例研究仍运行在模拟环境中，且只各测了 120 个实例，未能覆盖其全部工具生态和真实用户交互模式。

7. **攻击成本与检测成本未被量化**：论文未报告 ECLIPSE 在 SATS 阶段（沙箱迭代验证）的 API 调用次数、时间开销或失败轮次分布，也未见对防御检测延迟、误报率等运维指标的评估，难以判断攻击在现实时间约束下的可行性与防御部署的代价。
8. **未考虑攻击者的能力边界与鲁棒性**：框架假设攻击者有能力持续监控智能体执行轨迹并及时注入 DTC 残差信号；但在真实系统中，工具返回结果可能经过额外校验（如 JSON Schema 强校验、长度截断、去格式化），DTC 附加的自然语言指令可能因此在传输层被剥离，论文未评估此类“传输层扰动”对攻击成功率的影响。
9. **多轮交互与多智能体协作场景缺失**：实验仅覆盖单轮用户提示驱动的任务；对于需要多轮人机对话澄清、跨智能体协商或可中断/恢复的长期会话，ECLIPSE 的静态工作流编码是否能在上下文漂移后保持引导效力，仍属未知。

## 9. 复现性与开源状态

- 作者声明将发布 LASE-Bench 数据、ECLIPSE 攻击框架及 SATS/TCS 辅助代码，但明确保留受控恶意载荷（withheld artifacts），仅通过申请制向安全研究人员提供。

- 复现的主要障碍在于受害者模型 API 版本随时间的非固定性（如 GPT-5.6、Claude Sonnet 5 为论文中指定版本，后续 API 更新可能改变防御表现），以及基线方法（AdaptiveAttack、AdaptiveTools）的自适应改造细节未完全公开。

## 10. 启示与改进方向

- **对攻击研究**：ECLIPSE 表明“工具例程自动化”本身就是一种可利用的注入通道——只要工具描述中存在可被条件触发的状态机，攻击者无需在单条消息中暴露恶意意图，也能获得接近直接注入的可控性。未来攻击研究可进一步探索跨工具调用间的隐式状态传递（如通过文件系统、环境变量等非文本状态）作为第三通道。
- **对防御研究**：防御应跳出“内容过滤”思维，转向**轨迹级语义一致性检测**，例如对工具调用序列建模，识别不符合业务逻辑的状态转换；同时可将 DTC 信号视为一种需显式认证的“控制面信息”，要求工具返回内容中携带可验证的来源签名。
- **对基准建设**：LASE-Bench 的 120 个长周期恶意任务为社区提供了良好起点，但未来应扩展更多真实工具生态（如 SAP、Salesforce、Kubernetes RBAC）、更多语言/地域场景，并引入对抗性防御方共同迭代，避免静态基准被快速过拟合。

## 11. 总结

ECLIPSE 是首个系统性地聚焦长周期智能体提示注入中“隐蔽性与可控性”权衡的攻击框架。它通过用户提示与工具侧内容的双通道分布式注入，将攻击意图嵌入工具链的确定性流程，并利用静态工作流编码与动态轨迹校正两个机制确保执行过程不偏航。在 LASE-Bench 与 SHADE-Arena 上的多模型实验、消融分析及真实框架案例中，该方法均显著优于现有基线，证明了长周期任务场景对攻击者的天然红利。与此同时，论文也留下了若干开放性挑战：更强的工具侧完整性验证、轨迹级防御、多通道协作攻击的检测理论，以及更贴近真实部署的基准环境。总体而言，这项工作既是对提示注入攻击能力的一次重要扩展，也是对 LLM Agent 安全评测方法论的一次有益补充。
