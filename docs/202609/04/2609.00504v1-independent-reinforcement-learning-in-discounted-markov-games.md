## 摘要
在这项工作中，我们研究了折扣一般和马尔可夫博弈中的彻底非耦合学习。假设“用于PPAD的ETH”，我们证明，对于每个固定折扣因子，在分散设置中玩家独立学习时，不存在多项式时间算法来计算折扣一般和马尔可夫博弈中的逆多项式精度粗相关均衡。作为这一硬度结果的补充，我们提供了似乎是第一个在折扣一般和马尔可夫博弈中无需对博弈施加任何结构限制即可实现粗相关均衡的次指数收敛保证的彻底非耦合算法。我们的算法是乐观镜像下降的分层变体，具有针对多智能体环境定制的递增步长调度。最后，我们开发了上述算法的全反馈和部分反馈版本，并为每种情况建立了次指数收敛保证。

## Abstract
In this work, we study radically uncoupled learning in discounted general-sum Markov games. Assuming ``$\mathsf{ETH}$ for $\mathsf{PPAD}$", we show that, for every fixed discount factor, there is no polynomial-time algorithm for computing inverse-polynomially accurate coarse correlated equilibria in discounted general-sum Markov games when players learn independently in decentralized settings. Complementing this hardness result, we provide what appears to be the first \emph{radically uncoupled} algorithm with sub-exponential convergence guarantees to coarse correlated equilibria in discounted general-sum Markov games without imposing any structural restrictions on the game. Our algorithm is a \emph{layered} variant of optimistic mirror descent with an increasing step-size schedule tailored to the multi-agent setting. Finally, we develop both full-feedback and partial feedback versions of the aforementioned algorithm and establish sub-exponential convergence guarantees for each case.

## 1. 论文的核心问题与整体含义

**研究背景**

- 多智能体强化学习（MARL）广泛应用于博弈、语言模型、机器人、经济政策等场景，其理论基石是马尔可夫博弈（Markov/Stochastic Games）。
- 在一般和（general-sum）折扣马尔可夫博弈中，由于不存在零和博弈的鞍点结构，均衡的意义需要替换为粗相关均衡（CCE）等解概念。

**核心问题**

- 论文研究了“激进非耦合”（radically uncoupled）学习：博弈过程中，每个玩家 **不能** 观察其他玩家的策略、损失、价值函数或随机比特；没有共享随机性、通信或关联装置。每个玩家仅依据自身局部反馈独立更新策略。
- 在此信息约束下，核心开放问题是：是否存在（拟）高效的非耦合算法，能够近似求解折扣一般和马尔可夫博弈的 CCE？

**核心发现与含义**

- **下界：** 假设 "ETH for PPAD"（PPAD 的指数时间假设），对任意固定折扣因子 γ∈(0,1)∩Q，不存在多项式时间算法在线性稀疏支持下计算逆多项式精度的 CCE。这意味着独立学习场景下，多项式时间算法基本无望。
- **上界：** 文章提出了第一个不需要任何结构假设的激进非耦合算法，能在折扣一般和马尔可夫博弈中达到 **次指数收敛** 到 CCE 的保证（在自博弈/self-play 设定中）。
- 总体含义：在独立学习与一般和动态博弈的组合下，计算的“可行边界”落在准多项式时间附近，本文同时给出该边界的双侧逼近（quasi-polynomial upper bound 和 hardness 下界）。

## 2. 方法论

### 2.1 问题建模与均衡概念

- 研究对象为：
  - 有限时段（finite-horizon）一般和马尔可夫博弈；
  - 有限时段折扣博弈（长度 H̄<∞）；
  - 无限时段折扣博弈（H̄=∞）。
- 策略空间同时包含马尔可夫策略与历史依赖的（非马尔可夫）广义策略。本文的**后悔与 CCE 定义均针对非马尔可夫、历史依赖的偏离策略**，比常用的一阶马尔可夫偏离更强。

### 2.2 核心算法思想：分层 OOMD

- 论文提出**分层乐观镜像下降（Layered Optimistic Online Mirror Descent，LOOMD）**，在每个 “玩家-状态-层” 三元组 (i,s,h) 上独立执行乐观镜像下降。
- 关键技术设计：
  1. **平滑熵正则化器**  
     用带偏移 λ>0 的平滑负熵（smoothed entropy）作为 Bregman 正则化器，保证在单纯形上的 Bregman 散度有界，且对任意比较策略分布均允许。
  2. **递增的分层步长调度**  
     对第 h 层定义：
     - α_h = (3(H−h)+1)/(3H+1)
     - η_h = η₀ · T^(−α_h)  
     因此越靠后的层学习率越大（因为 α_h 越小），越靠前的层学习率越小（更平稳）。小步长抑制早期层的策略漂移，使后层的“历史占据权重”缓慢变化；大步长让下游更快适应。
  3. **优化（optimism）机制**  
     执行乐观更新，利用上一轮的 Q 函数作为本轮的预测，以减小对连续 Q 值波动的敏感度。

### 2.3 理论分析框架

全文证明的主要流程分为三步：

1. **后悔分解**：把总的历史依赖后悔加权分解为逐层的局部加权后悔；
2. **稳定性控制**：利用近端算子的 Lipschitz 性质、历史核的 ℓ₁ 收缩性质，控制隐藏权重与 Q 值函数的漂移；
3. **步长平衡**：选取上述分层步长，使所有误差项同阶。

**主要结果为：**
- 全反馈（full-feedback）：Regret = O(T^(−3/(3H+1))) 近似 CCE。
- 部分反馈（partial feedback）：在引入 (κ, ζ)-可达性条件后，通过分块估计 Q 函数和强制探索下界，得到相同指数依赖的 CCE 保证及多项式样本开销。

### 2.4 折扣博弈的传递原理与截断

- 由于折扣使得远期贡献按 γ 的指数衰减，可将折扣博弈截断为前 L 层的有限时段博弈，截断误差 ≤ γˡ/(1−γ)。
- 选择有效折扣地平线 L ∝ log(1/ε)，再运行有限时段的算法，即可将有限时段误差转化到折扣情形。  
  由于 L = O(log(1/ε))，**总迭代次数变成 quasi-polynomial（拟多项式）**（指数为 O(min{H̄, log(1/ε)}）），克服了原算法中随 H 指数增长的问题。

### 2.5 计算下界：还原与构造

- 将 bimatrix game 的近似纳什均衡计算多项式时间归约为有限时段马尔可夫博弈的稀疏 CCE 计算，再进一步嵌入折扣无限时段博弈中。
- 组合两个关键构造：
  1. FH(M)：对数级别时长的马尔可夫博弈嵌入；
  2. 将任意有限时段 GH 转换成无限时段折扣博弈 G̃_H,γ（第 H 步强制进入吸收状态）。
- 结合 Rubinstein (2016) 关于 PPAD-ETH 对双矩阵博弈的硬度结论，得到：
  - 不存在多项式时间算法求解 (N^C, N^(−K))-DiscSparseMarkovCCE_gen^γ；
  - 该下界直接适用于分散/非耦合学习任务。

## 6. 主要结论与发现

1. **计算下界**：
   - 在 "ETH for PPAD" 假设下，任意固定 γ∈(0,1)∩Q，不存在多项式时间算法计算逆多项式精度的稀疏折扣 CCE（无论是有限还是无限时段一般和折扣马尔可夫博弈），当玩家在分散设置中独立学习时尤其如此。
2. **正算法（首次）**：
   - 提供了第一个不引入任何结构假设的激进非耦合算法，通过分层乐观镜像下降和递增步长调度，在折扣一般和马尔可夫博弈中实现次指数收敛到 CCE。
3. **全反馈与部分反馈**：
   - 两种模型都可获得同样的次指数依赖（即 O(T^(−3/(3H+1))) 扩展转化为 quasi-polynomial 迭代次数），其中部分反馈版本经过 Q 值估计、分块和探索下限处理，代价是多项式级别的样本开销。
4. **复杂度上下界基本匹配**：
   - 准多项式上界无法在论文的一般性条件下改进为多项式算法，除非 PPAD-ETH 被推翻。

## 7. 优点
