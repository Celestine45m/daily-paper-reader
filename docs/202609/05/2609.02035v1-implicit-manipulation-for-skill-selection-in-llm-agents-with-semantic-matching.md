## 摘要
技能选择是LLM智能体工作流中的关键阶段，决定哪个已安装技能应处理用户请求。现有的针对该阶段的攻击主要依赖于显式提示注入或指令级操纵，这可能会暴露可识别的操纵信号。在这项工作中，我们识别了一个新的隐式攻击面：即使用户提示和技能描述在孤立情况下看似良性，它们的语义关系仍可被策略性塑造，以偏向攻击者选择的技能。基于这一观察，我们提出了通过语义匹配的隐式技能选择操纵（ISM），它联合塑造目标技能元数据和可复用提示，在没有显式选择指令的情况下操纵技能选择。具体而言，我们开发了一个三阶段策略，以拓宽语义覆盖范围、增强目标独特性并保持提示的自然措辞。在四个任务领域和八个选择器模型上，ISM将平均目标选择率（TSR）从15.2%提升至63.5%。在匹配比较中，ISM实现了73.5%的TSR，仅比显式操纵低9.8个百分点。人类审查者在仅2.9%的判断中阻止ISM，而显式操纵为91.4%；同时，五个基于LLM的检查器对ISM的平均通过率为82.9%，而显式操纵仅为37.4%。此外，ISM对PPL-W、Llama Prompt Guard 2和PIGuard依然有效。

## Abstract
Skill selection is a key stage in LLM-agent workflows, determining which installed skill should handle a user request. Existing attacks on this stage primarily rely on explicit prompt injection or instruction-level steering, which can expose recognizable manipulation signals. In this work, we identify a new implicit attack surface for skill selection: even when the user prompt and skill description appear benign in isolation, their semantic relationship can still be strategically shaped to favor an attacker-chosen skill. Based on this observation, we present Implicit Skill-Selection Manipulation via Semantic Matching (ISM), which jointly shapes target-skill metadata and reusable prompts to manipulate skill selection without explicit selection instructions. Specifically, we develop a three-stage strategy to broaden semantic coverage, strengthen target distinctiveness, and preserve natural prompt wording. Across four task domains and eight selector models, ISM increases the average target-selection rate (TSR) from 15.2% to 63.5%. In a matched comparison, ISM achieves a 73.5% TSR, only 9.8 percentage points below Explicit Steering. Human reviewers block ISM in only 2.9% of judgments, versus 91.4% for Explicit Steering, while five LLM-based inspectors pass ISM at an average rate of 82.9%, versus 37.4% for Explicit Steering. Moreover, ISM remains effective against PPL-W, Llama Prompt Guard 2, and PIGuard.

# 2. 方法论：核心思想、关键技术与流程

## 2.1 核心思想

作者提出 **ISM（Implicit Skill-Selection Manipulation via Semantic Matching，基于语义匹配的隐式技能选择操纵）**。其核心洞察是：**合理利用 LLM 选择器内部基于语义匹配的决策机制，在不引入任何显式选择指令的条件下，双向协同地修改“提示词”（prompt）与“目标技能元数据”（skill description），使二者在嵌入空间中形成天然的语义对齐，从而让选择结果自然地偏向攻击者所控制的技能。**

模型层面，ISM 使用语义相似度作为衡量工具（如公式 \( S(x,y) = \frac{E(x)^\top E(y)}{\|E(x)\|\|E(y)\|} \)），并观察到语义匹配分数与目标选择率之间存在正向关联，由此驱动攻击内容设计。

## 2.2 关键技术：三阶段攻击策略

ISM 通过三个有序阶段逐步完成操纵：

### 阶段#1：任务相关线索构建——扩展语义覆盖

- **目的**：让目标描述对同一任务场景下不同措辞和不同表述的用户请求都具备兼容性，从而将攻击扩展到用户对可复用提示的个性化变体。
- **做法**：
  - **场景导向过滤**：从同一场景的大量可复用提示中提取跨提示高频出现的短语。
  - **任务导向过滤**：结合目标技能描述进行语义相关性筛选，只保留与目标任务相关的短语。
  - 通过“跨提示频率”（FRP）与“语义相似度”的加权排序（公式 \( R(c) = \frac{1}{2}FRP(c) + \frac{1}{2}\tilde{S}(c, m_t) \)）挑选线索。
  - **双向融合**：将提示侧高频共享线索提取为语义线索加入目标描述；同时将描述侧能力短语转换为任务要求加入提示文本。

### 阶段#2：定制化技术钩子注入——增强目标区分度

- **目的**：同域技能（功能相似的竞争技能）可能共享高频语义线索，因此需要引入目标独特的技术性表述，让目标技能在同域竞争中脱颖而出。
- **做法**：
  - 设计诊断性实验发现：现有技能描述以任务层次（capability-oriented）表述为主，缺少数具体技术细节；而技术性词汇占比很小（见图3c）。
  - 引入“技术钩子”（technical hook），即目标技能真实支持的、与当前任务语境一致但较少出现在竞争技能描述中的技术表述（如“语义关键点提取”“分节感知幻灯片分解”等）。
  - 将钩子同时注入目标描述（作为技术能力详情）和提示词（作为任务要求）。实验表明目标相关钩子能降低选择熵（即增强选择集中度）并提升目标选择率。

### 阶段#3：提示自然化——维持隐式性

- **目的**：直白的技术措辞会让提示词显得刻意、可疑，因此需要对提示侧的技术钩子进行自然化改写，同时保留其含义，而目标描述侧保留技术形式。
- **核心技术——“语义约束的自然化”（Semantic-Constrained Naturalization）**：
  - **语义关系判定**：借鉴 WordNet、ConceptNet、FrameNet 的资源，定义四类“语义桥”——**分类关系（taxonomic）、部分–整体关系（part–whole）、目标–功能关系（goal–function）、使用语境关系（use-context）**，用于把技术钩子与自然用户表达连接起来。
  - **语义桥约束的改写**：将语义桥交给 LLM，指引其在上下文中自然地实现用户层含义，并约束不得直接复用技术词汇、不得引入显式选择指令。
  - **改写后检查**：逐一验证是否保留原始任务、是否保留指定语义关系、是否减少了直接技术措辞、是否读起来像自然用户请求；不满足则拒绝并重新生成。
- **效果验证**：语义约束自然化相比通用改写显著保留了目标相关性裕度（relevance margin），同时维持低风险分数（见图5），而显式引导则被检测出极高风险。

# 6. 论文的主要结论与发现

1. **显式指令并非操纵技能选择所必需**：仅靠语义协同匹配即可有效改变技能选择结果。
2. **有效性**：
   - ISM 将宏平均目标选择率（macro TSR）从 Native 的 15.2% 提升到 63.5%（绝对提升 48.3 个百分点）。
   - 所有 8 个选择器模型均出现正向宏增益；64 个模型–目标组合中有 62 个为正。
   - 8 个目标技能在四个领域均呈现正增益（从 +22.6pp 到 +70.8pp）。
3. **与显式攻击对比**：匹配对比中 ISM 的 TSR 达 73.5%，仅比显式引导（83.3%）低 9.8 个百分点。
4. **隐式性（Implicitness）大幅提升**：
   - 人类评审阻断率：ISM 仅 2.9%，而 Explicit Steering 为 91.4%。
   - 5 个 LLM 检查器的平均放行率：ISM 高达 82.9%，Explicit Steering 仅 37.4%。
5. **规则防御覆盖率有限**：
   - PPL-W 对 ISM 的阻断率为 0%；Prompt Guard 2 和 PIGuard 的阻断率分别只有 25.4% 和 23.1%。
   - 但即使经过 PG2/PIGuard 过滤，残留目标选择率仍近半（47.8%/46.9%）。
   - 同时这些规则防御在良性输入上产生 26.5%/37.5% 的高误报率，呈现明显的“安全–效用”困境。
6. **各阶段贡献量级明确**：
   - Cue：平均 TSR 从 15.2% 提升到 47.8%（+32.6 pp）
   - Hook：进一步升至 79.2%（+31.4 pp）
   - Naturalization：回落到 63.5%（−15.7 pp，换取隐式性）

- **对隐式性进行了严格验证**：不仅测量攻击效果，还通过人类评审 + LLM 审查 + 规则防御三重维度系统测量“可识别性”，构建立体的实证证据。
- **语义约束的自然化方法论**：借助语义桥（semantic bridge）与重写后检查环节，创造性地解决了“保留语义匹配”与“去除技术性异常”之间的矛盾，并将其提炼为可泛化的方法。
- **实验覆盖广**：评估了八种选择器模型、四种差异化任务域、多组目标技能与同域竞争者组合，并包含消融、诊断、对比、泛化（自定义提示）等多样实验，显著提高了结论的普适性。
- **回应了真实生态风险**：结合提示词市场与技能注册中心的现实传播路径（AIPRM、PromptBase、MCP Registry 等庞大用户数据），指出攻击的生态扩散潜力，具备现实紧迫性。

# 8. 不足与局限

- **下游影响未被评估**：论文明确将范围限定在执行前的“技能选择”阶段，未曾模拟或证实被选中技能的恶意后端在最终执行时是否会真正造成危害，也未验证攻击技能的端到端安全影响。
- **实验资源信息缺失**：未披露 GPU 数量、推理成本、时间等硬件资源细节，降低了可复现评估的资源参考价值。
- **个别模型效果有限**：Llama-2-7B（较旧的 7B 开源模型）上出现少量负增益（64 组中有 2 组为负），说明攻击对部分弱/旧模型的驱动能力存在局限。
- **防御方案仍处概念阶段**：论文提出的“结构性改写”（structural rephrasing）防御设想停留在方向性讨论，并未给出完整实现与效果评估。
- **语义测量的偏倚风险**：方法依赖 MiniLM 作为语义度量（选择器本身并未使用同一嵌入模型），虽然实验说明了与选择率的相关性，但 MiniLM 捕获的语义可能与真实 LLM 选择器的内部匹配机制存在系统偏差。
- **人工审查样本量较小**：仅有 7 名技术背景评审者参与了条件隐藏检查，样本的职业结构与规模有限，结论难以泛化到一般人群的识别能力。
- **提示词个性化泛化仅为有限改进**：在用户不使用攻击方发布的可复用提示词、而是自行书写提示词的场景下（即只改进描述侧 Cue 描述），宏平均 TSR 仅从 15.4% 到 27.4%，远低于完整攻击效果，表明攻击对“非复用提示用户”的实际影响力有限。
- **后检查角度未考虑端到端检测链**：文中按顺序分别评估各类检查，但未评估人类+LLM+规则防御组合的协同检测效果，亦未讨论更复杂的自适应防御场景。
- **关系类别子集化**：在自然化阶段仅采纳了四类语义关系（分类、部分–整体、目标–功能、使用语境），可能遗漏其他可比较的语义桥结构。
