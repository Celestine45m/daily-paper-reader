## 摘要
LLM 智能体正越来越多地用于安全任务：漏洞发现、漏洞利用复现和补丁生成。在模型层面改进它们需要专家示范或可计算奖励，而安全任务很少提供这些：轨迹成本高昂，失败难以诊断，奖励稀疏且不可计算。因此，相关工作转向执行框架和上下文，但人工调参需要任务特定专业知识，且难以扩展；自动方法则依赖稀缺的真实标注、更强的优化器模型，或无引导的提议-评估循环，后者退化为代价高昂的试错。我们提出 SelfOp，一种自动改进冻结的安全智能体任务上下文（指令、技能和参考文档）的算法，且不修改其执行框架和模型权重。SelfOp 将上下文优化建模为受链式法则启发的文本梯度下降：从单个实例的结果出发，它将误差信号反向传播经过评估器、智能体轨迹以及塑造其行为的上下文制品，产生逐实例文本梯度。梯度通过聚类、排序和过滤在实例间累积，并且仅在跨实例共识下提交。收敛检测器监控梯度信号本身，一旦上下文吸收了训练数据中可泛化的信息便停止，无需留出验证数据。我们在 CyberGym 上评估 SelfOp，这是一个真实世界漏洞复现任务的基准。在少于 200 个训练样本的情况下，SelfOp 使 GPT-5.4-mini（搭配 Codex）自我提升 17 分，足以超过前沿 GPT-5.4 基线 6 分，并使 GPT-5.4 本身自我提升 18.5 分。优化后的技能还可跨模型迁移，表明 SelfOp 优化的技能学到的是可泛化的任务知识，而非模型特定模式。

## Abstract
LLM agents are increasingly used for security tasks: vulnerability discovery, exploit reproduction, and patch generation. Improving them at the model level demands expert demonstrations or computable rewards, which security tasks rarely offer: traces are costly, failures hard to diagnose, rewards sparse, and non-computable. Efforts thus shift to the harness and context, but manual tuning needs task-specific expertise and scales poorly, while automated methods rely on scarce ground truth, stronger optimizer models, or unguided propose-and-evaluate loops that reduce to costly trial and error.   We introduce SelfOp, an algorithm that automatically improves a frozen security agent's task context (instructions, skills, and reference documents), without modifying its execution harness and model weights. SelfOp casts context optimization as chain-rule-inspired textual gradient descent: from a single instance's outcome, it propagates error signals backward through the evaluator, the agent's trajectory, and the context artifacts that shaped its behavior, yielding per-instance textual gradients. Gradients are accumulated across instances by clustering, ranking, and filtering, and committed only under cross-instance consensus. A convergence detector monitors the gradient signal itself and stops once the context has absorbed the generalizable information in the training data, without held-out validation data.   We evaluate SelfOp on CyberGym, a benchmark of real-world vulnerability reproduction tasks. With fewer than 200 training examples, SelfOp yields a 17-point self-improvement for GPT-5.4-mini (with Codex), enough to surpass the frontier GPT-5.4 baseline by 6 points, and an 18.5-point self-improvement for GPT-5.4 itself. The optimized skills also transfer across models, highlighting that SelfOp-optimized skills learn generalizable task knowledge not model-specific patterns.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体已用于漏洞发现、漏洞利用复现、补丁生成等安全任务，但在新任务或新领域表现不佳时，如何让智能体自我改进是一个关键问题。
- **三类改进路径的局限**：
  - **改进模型权重**：需要专家示范、教师轨迹、可计算奖励、可插桩环境，安全领域这些资源稀缺，且训练成本高、依赖更强教师。
  - **改进执行框架 / harness**：需要大量领域专业知识和人工设计，自动搜索方法也常依赖强编码智能体和昂贵试错。
  - **改进上下文 / context**：相对最可行，包括指令、技能、参考文档等，但人工调优难扩展；现有自动上下文优化方法又存在单次分析、依赖验证集、依赖真值或更强优化器、无引导提议-评估循环等问题。
- **安全任务的特殊挑战**：
  - 漏洞通常没有唯一标准答案，同一漏洞可由不同 PoC 触发、由不同补丁修复，存在解等价类。
  - 奖励常为稀疏二值信号，失败难以诊断，成功轨迹昂贵。
  - 因此不能简单针对某个参考解优化，否则会 shortcut learning。
- **论文整体含义**：提出 **SelfOp**，在不修改冻结模型权重和执行框架的前提下，自动优化安全智能体的任务上下文，使其通过文本梯度下降式流程实现自我改进。核心主张是：结构化上下文优化本身即可带来显著性能提升，且无需更强教师模型或留出验证集。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想

- 将上下文优化类比为**链式法则启发的文本梯度下降**。
- 可学习参数 \(\theta\) 是智能体技能上下文，例如 `poc-generation` 的 `SKILL.md` 和参考文档。
- 冻结模型 \(M\) 和 harness \(H\)，仅更新 \(\theta\)。
- 优化循环：
  1. 在任务批次上前向执行智能体，得到二值 pass/fail 损失 \(L\)。
  2. 反向传播误差，生成逐任务文本梯度。
  3. 跨任务累积、聚类、排序、过滤梯度。
  4. 通过收敛检测决定何时停止。
  5. 优化器根据结构策略 \(\psi\) 和结构检查器更新上下文。

### 2.2 链式法则式反向传播

论文将反向过程分解为：

\[
\frac{\partial L}{\partial \theta_{\text{skill}}}
=
\frac{\partial L}{\partial s}
\cdot
\frac{\partial s}{\partial \tau}
\cdot
\frac{\partial \tau}{\partial \theta_{\text{skill}}}
\]

其中 \(L\) 是二值损失，\(s\) 是评估分数，\(\tau\) 是智能体轨迹，\(\theta_{\text{skill}}\) 是技能上下文。

- **Stage 1：\(\partial L/\partial s\)，分数分析**
  - 将二值损失分解为具体评估标准。
  - 例如 CyberGym 中：是否生成 PoC 文件？是否使 pre-patch 二进制崩溃？是否触发目标 sanitizer？
  - 用于定位失败发生在评估流水线的哪一环。

- **Stage 2：\(\partial s/\partial \tau\)，轨迹分析，skill-blind**
  - 给定分数、轨迹和漏洞元数据 \(\mu_v\)，分析哪些行为导致该结果。
  - 该阶段不查看当前 skill \(\theta\)，避免分析被现有指令锚定。
  - 利用漏洞元数据重建结构不变量 \(\hat{\phi}_v\)：
    \[
    \hat{\phi}_v = \text{RECONSTRUCT}(\mu_v)
    \]
  - 目标是判断智能体是否偏离了漏洞的根本原因、触发条件和失败模式，而不是只对比某个参考 PoC。

- **Stage 3：\(\partial \tau/\partial \theta_{\text{skill}}\)，编排分析，skill-aware**
  - 根据 Stage 2 的行为分析，识别当前 skill 中哪些指令的缺失或存在导致了问题。
  - 提出针对性编辑建议。
  - 例如论文例子 `arvo_3956`：智能体把 curl 回归测试 `test1800` 当作 PoC，Stage 3 发现 `SKILL.md` 缺少“不要把已有回归测试当漏洞触发输入”的负向指令。

### 2.3 梯度累积

- 动机：逐任务梯度直接交给优化器会产生方向问题和幅度问题。
- 方向问题包括：
  - 负性偏差：只看失败任务，忽略成功经验。
  - 强度侵蚀：采纳与已验证优势相矛盾的修改。
  - 低支持噪声：仅由少数任务支持的修改被采纳。
  - 矛盾采纳：互相矛盾的梯度同时被采纳。
- 幅度问题：
  - 优化器无法区分“skill 完全没覆盖的缺口”与“skill 已覆盖但执行不足”的模式。
  - 导致重复添加内容、上下文膨胀、指令稀释。
- 解决流程：
  1. **提取与聚类**：从逐任务梯度提取原子 strengths / improvements，聚类为主题。
  2. **排序与过滤**：
     - 复合评分：
       \[
       \text{composite}(t)
       =
       \alpha \cdot \frac{|\text{tasks}(t)|}{|\text{batch}|}
       +
       \beta \cdot w(t)
