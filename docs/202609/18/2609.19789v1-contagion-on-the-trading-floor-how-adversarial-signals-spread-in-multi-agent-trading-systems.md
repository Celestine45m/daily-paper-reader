## 摘要
基于大语言模型（LLMs）构建的多智能体交易系统正开始出现在量化金融领域，但其对抗性输入的鲁棒性在很大程度上仍属未知。我们研究了 LLM 交易栈对黑盒、仅输入攻击的脆弱性，这些攻击仅通过可允许的社交媒体信息流进入。我们引入了通用多智能体交易系统（GMATS），这是一个刻画现代多智能体交易架构的框架，并实例化了一类黑盒投毒攻击者：其将 LLM 视为帖子生成器，并向分析师的证据流中注入受预算约束、看似无害的社交媒体内容。我们定义了传染度量，以追踪对抗性内容如何在交易栈中传播，包括分析师层与协调器层的信念偏移分数，以及标准回测指标上的攻击-干净差值。在包含历史市场与社会数据的安全离线基准上的实验表明，即使简单的仅输入攻击者也能实质性地恶化风险收益特征，显著降低夏普比率。与此同时，我们发现，设计得当的多智能体拓扑与协调器提示可以缓冲对抗性冲击，并在相同投毒预算下提高平均鲁棒性。

## Abstract
Multi-agent trading systems built on large language models (LLMs) are beginning to appear in quantitative finance, yet their robustness to adversarial inputs is largely unknown. We study the vulnerability of LLM trading stacks to black-box, input-only attacks that enter solely via admissible social-media feeds. We introduce the Generic Multi-Agent Trading System (GMATS), a framework that captures modern multiagent trading architectures and instantiate a class of black-box poisoning attackers that treat an LLM as a post generator and inject budget-constrained, plausibly benign social-media content into the analyst's evidence stream. We define contagion metrics that trace how adversarial content propagates through the stack, including belief-shift scores at analyst and coordinator layers and attack-clean deltas on standard backtest metrics. Experiments on a safe offline benchmark with historical market and social data show that even simple input-only attackers can materially degrade risk-return profiles, sharply reducing Sharpe ratios. At the same time, we find that suitably designed multi-agent topologies and coordinator prompts can dampen adversarial shocks and improve average robustness under identical poisoning budgets.

# 论文总结：Contagion on the Trading Floor

## 一、核心问题与整体含义

- **研究动机**：基于大语言模型（LLM）的多智能体交易系统（如 TradingAgents、TradingGroup、ContestTrade、QuantAgent）正快速进入量化金融领域，并在回测中报告了显著收益。然而，这些系统在**对抗性输入**下的鲁棒性几乎未被系统研究。
- **核心问题**：多智能体、纯 LLM 交易系统对**仅通过合规证据流（社交媒体）进入的黑盒、输入型攻击**有多脆弱？
- **背景张力**：
  - 已有结果（如 AgentSmith）表明，单一对抗输入可在多模态 LLM 智能体间指数级传播，说明**组合可能放大而非缓解漏洞**。
  - 社交媒体是最大对抗攻击面（高量、弱审核、易注入虚假信息），但移除社交媒体分析师并不现实，因为情绪与资金流信号是许多股票策略的主要收益驱动。
- **整体含义**：本文首次系统研究 LLM 原生多智能体交易栈对黑盒输入型攻击的鲁棒性，揭示其脆弱性，同时发现合理的多智能体拓扑与协调器设计可作为防御手段。

## 二、方法论

### 2.1 核心思想：GMATS 统一框架

- 提出 **Generic Multi-Agent Trading System (GMATS)**，抽象现代 LLM 多智能体交易系统的共性结构。
- 形式化定义为一个元组：
  `G = (A, A, C, K, X, S, Σ, D, L, Λ, E)`
  - **A**：资产集合；**A/C/K/X**：分析师/协调器/控制器/执行器智能体
  - **S**：有限消息类型集合；消息 `m = (id, src, dst, τ, payload, ts)`
  - **Σ**：调度表，每轮执行 `A → C → K → X` 流水线（允许微轮）
  - **D**：时点（PIT）数据源；**E**：执行环境
  - **L/Λ**：协调逻辑与风险控制逻辑
- **不变量**：时点纪律（ts ≤ t）、可回放性（完整日志）、模式安全（仅良类型消息可路由）。
- **订单空间**：离散 `O_disc = {-1, 0, 1}^n`，连续 `O_cont ⊆ R^n`。

### 2.2 理论贡献

- **定理 1（GMATS 表达力）**：任何满足「类型化消息传递 + 时点纪律 + 阶段分离」的多智能体交易流水线，均可编译为行为等价的 GMATS 实例（在相同初始状态与随机种子下产生相同订单序列）。
- **推论 1**：TradingAgents、TradingGroup、ContestTrade、QuantAgent 均满足条件，可映射到 `A → C → K → X` 管道。

### 2.3 传染度量指标

- **毒化消费率**：`p_poison = (1/T) Σ |Top_k(t) ∩ P| / k`，实验中目标水平为 15%–75%。
- **信念信号偏移（BSS）**：
  `BSS = (1/TN) Σ_t Σ_i (f^attack_{i,t} − f^clean_{i,t})`
  正值表示攻击下信念更看涨，负值表示更看跌。
- **性能指标（FinSABER 协议）**：累计收益 CR、年化收益 AR、年化波动 AV、夏普比率 SR。
- **差值报告**：`Δm = m_attack − m_clean`，隔离攻击净效应。

### 2.4 攻击者模型

- **随机攻击者**：每日按预算生成随机情绪方向帖子，作为最小噪声基线。
- **始终负面攻击者**：每日全部预算生成强烈看跌帖子，模拟持续负面叙事（如「做空并散布」）。
- **范围与准入假设**：衡量的是对抗内容**已进入**社交证据流后的下游传染，不建模内容如何被创建/推广/过滤；`p_poison` 作为抽象旋钮，捕捉发布强度与上游放大。

## 三、实验设计

## 六、主要结论与发现

1. **方向性投毒远比随机噪声危险**：
   - 随机攻击者仅造成轻微变化，ΔCR 和 ΔSharpe 很小甚至略正。
   - 始终负面攻击者随 `p_poison` 增加系统性恶化夏普与累计收益，在 **30%–45% 摄入率附近出现明显状态转变**（ΔSharpe 从 +0.86 骤降至约 −6）。
2. **信念传染呈剂量–响应**：
   - 始终负面攻击者下，BSS_analyst 从 15% 时约 −0.78 降至 75% 时约 −1.41；协调器层 BSS 负向较小但显著，说明部分阻尼但未完全吸收。
3. **架构是一阶因素**：
   - **单智能体最脆弱**：BSS_analyst 约 −1.1 至 −1.5，ΔSharpe 约 −7 至 −9。
   - **宽协调器拓扑反而阻尼冲击**：ΔCR 接近零，低毒化率下 ΔSharpe 甚至为正。
4. **防御型协调器设计有效**：
   - **宽协调器多空**：强制显式正反分解，融合后 BSS 居中（约 −0.4 至 −0.6），ΔSharpe 在所有毒化率下为正。
   - **成对三角协调器**：融合 BSS 始终比任一内部协调器更温和，ΔSharpe 全为正，三角规则成功降权极端攻击对齐视图。
5. **跨模型一致性**：
   - Qwen2.5-7B 复现保持相同定性结论：方向性投毒最有害、单智能体最脆弱、防御型协调器最稳健；但具体幅度依赖模型。
6. **TradingAgents 基线**：同样呈现方向性社交传染，但下游被阻尼，表现为「攻击下风险抑制」而非盈利改善。
