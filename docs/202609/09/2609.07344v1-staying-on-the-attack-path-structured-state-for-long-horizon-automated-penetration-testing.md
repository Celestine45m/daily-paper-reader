## 摘要
基于大语言模型（LLM）的智能体越来越多地应用于漏洞发现和自动化渗透测试等网络安全任务。然而，在长时域安全任务中，此类智能体仍受制于上下文遗忘和意图漂移：早期关键事实和因果推理链在长时间交互中丢失，智能体陷入无目的的重复探索。本文提出Intentest，一种意图图引导的自动化渗透测试智能体，将长时域状态从LLM的上下文窗口外部化到持久化的事实-意图有向无环图（DAG）上，从而显著减少无效转换。我们在Web应用自动化渗透测试这一网络安全中具有代表性的长尾任务上评估Intentest。在DAG中，已验证的网络状态存储为不可变事实节点，探索方向被约束为受前驱事实限制的意图边。该系统采用三层架构，其中事实-意图映射层维护全局状态，任务调度与分配层通过两阶段降级恢复和多维自适应负载均衡确保执行稳定性，意图检索与预测层通过自顶向下的五阶段过滤算法提供战术先验。在覆盖三个难度级别、十多种漏洞类型的真实CTF挑战基准上，Intentest实现了88.2%的总体成功率和75.0%的困难任务成功率，较基线分别提升约44和50个百分点。消融实验进一步表明，在不改变可解任务集合的情况下，意图检索与预测将成功的中等和困难任务的平均轮次分别减少约33%和48%。

## Abstract
Large language model (LLM) based agents are increasingly applied to cybersecurity tasks such as vulnerability discovery and automated penetration testing. On long-horizon security tasks, however, such agents remain limited by context forgetting and intent drift: early critical facts and causal reasoning chains are lost over extended interactions, and the agent falls into aimless, repetitive exploration. This paper proposes Intentest, an intent-graph-guided automated penetration testing agent that externalizes long-horizon state from the LLM's context window onto a persistent fact-intent directed acyclic graph (DAG), thereby substantially reducing invalid transitions. We evaluate Intentest on automated penetration testing of web applications, a representative long-tail task in cybersecurity. In the DAG, verified network states are stored as immutable fact nodes, and exploration directions are constrained as intent edges bounded by predecessor facts. The system adopts a three-layer architecture, in which the fact-intent mapping layer maintains the global state, the task scheduling and allocation layer ensures execution stability through two-phase degradation recovery and multi-dimensional adaptive load balancing, and the intent retrieval and prediction layer provides tactical priors through a top-down five-stage filtering algorithm. On a benchmark of real CTF challenges covering more than ten vulnerability types across three difficulty levels, Intentest achieves an overall success rate of 88.2% and a success rate of 75.0% on hard tasks, improving over the baseline by approximately 44 and 50 percentage points. Ablation experiments further show that the intent retrieval and prediction reduce the average number of rounds on successful medium and hard tasks by about 33% and 48%, respectively, without changing the set of solvable tasks.

- **研究背景**：基于大语言模型（LLM）的智能体逐渐被应用于漏洞发现、自动化渗透测试等网络安全任务，显示出环境感知、代码生成和逻辑推理等能力。
- **核心问题**：LLM 智能体在长时域（long-horizon）安全任务中面临两大结构性缺陷：
  - **上下文遗忘（Context Forgetting）**：交互过程中，早期发现的关键微事实被大量冗余日志和无效操作稀释，因上下文窗口截断而丢失；
  - **意图漂移（Intent Drift）**：随着任务推进，智能体逐渐偏离最初设定的渗透目标，陷入无目的的重复探索和局部死循环。
- **在渗透测试场景中的表现**：此类任务属于典型高维、高不确定性的长尾任务，攻击链的构建往往依赖在不同时间点、不同网络层获得的事实之间的因果推理；现有纯文本上下文窗口难以建模这种非线性、联网状的因果关系。
- **已有方法为何不够**：
  - 基于任务树的方案（如 PentestGPT）过于依赖人工干预，文本任务树在事实大量增长时仍会超出上下文限制；
  - 多智能体共享文本记忆的方法（如 VulnBot）对深层因果链理解不足，容易被噪声干扰；
  - 经典规划方法依赖预定义谓词和确定性动作空间，面对 0-day 和非标准化漏洞时缺乏泛化性；
  - 单纯 RAG 检索是"无状态"的局部文本相似匹配，可引入因果幻觉；
  - 对公共报告进行 SFT 微调存在严重幸存者偏差。

### 2. 方法论：Intentest 系统设计

#### 核心思想：事实-意图 DAG（Fact-Intent DAG）

系统将 LLM 原本在上下文窗口中维护的全局状态（belief state）**外化**到持久化的图数据库中，缓解模型自身的记忆负担：

- **事实节点（Fact Nodes）**：所有经过实际验证的网络状态，不可变、不可被 LLM 凭空捏造；
- **意图边（Intent Edges）**：候选探索方向，只能由已验证的前驱事实触发；
- **前置条件校验（Structural Precondition Validation）**：任何不基于已验证事实的意图（如被提示注入诱导的破坏性建议）在结构上就被拒绝，不能获得执行授权。

网络被建模为 POMDP ⟨S, A, T, O, Ω, R⟩，但传统 POMDP 依靠线性上下文窗口维护内部信念状态，本文通过图形化状态机替代这一做法，使决策沿着由图结构保证的因果一致路径推进。

#### 三层架构

- **事实-意图映射层**：维护全局状态黑板，管理任务、事实、意图、意图来源、提示词、作用域等核心表，构建异步多智能体间唯一的间接通信媒介；
- **任务调度与分配层**：
  - 对所有任务拆分为三种操作：Bootstrap、Explore、Reason；
  - 引入意图节点四状态有限状态机：CREATED → CLAIMED → CONCLUDED → COMPLETED（超时回收回 CREATED 重新认领）；
  - **多维自适应负载均衡**：依次经过协议一致性仲裁、容量安全检查、健康探测、优先级权重选择、活跃负载均衡、随机抖动六步筛选，将任务公平分配到最佳执行节点；
  - **两阶段降级恢复机制**：执行超时后不立即销毁容器，而是注入紧急截断提示，强制停止网络层探测后收集残存的 stdout/stderr 日志，从中恢复部分事实并写回图；
- **意图检索与预测层**：融合三类有向图（离线基础意图图、实时攻击图、合并图），抵御传统 RAG 噪声，并通过异步意图桥控制器将战术建议注入上下文。

**意图也做了模型化：Goal 定义为宏观稳态目标，Action 为底层执行命令，Intent 是连接二者的战术承诺（约束于当前离线知识）。**

#### 五阶段意图检索与预测算法（自顶向下）

1. **语义初筛**：使用 Qwen3-Embedding-4B 将当前图属性向量化，按余弦相似度保留 Top-k 候选；
2. **子图同构验证**：对候选意图的前驱子图施加图同构约束，去除了仅靠词面重合造成的幻觉；
3. **降级模糊统计推理**：当同构检查失败时退化为基于 Jaccard 系数的模糊匹配，容忍真实环境的部分拓扑缺失与噪声；
4. **战略意图对齐**：将候选项与授权最终目标对齐，剪除偏离主线攻击链的分支；
5. **LLM 启发式推理**：无历史特征可匹配时，注入降维后的环境日志和残存拓扑，依靠 LLM 做探索性判断。

第五阶段的输出仍需经 DAG 前置验证，不可直接执行。

#### 与既有框架的关系（概念映射上有一定创新）

- 将经典 POMDP 推理重新表达为受图约束的状态转移，
- 将 BDI（Belief-Desire-Intention）智能体理论与对抗性网络安全场景结合，
- 以图结构状态（状态持久化能力）和调度机制共同界定系统能否求解任务。

### 7. 方法或实验设计的优点

1. **图结构化状态设计贯穿落地**：事实仅由代码实际验证产生，意图仅由前驱事实触发，从体系结构上强制因果一致性并阻断提示注入类非授权执行，比纯用提示约束方法强壮且易于解释；
2. **存储交互解耦**：用持久图数据库替代 LLM 上下文作为全局事实来源，对事实检索、条件约束、跨步骤因果链都有天然的可靠性，削弱了"上下文越长越靠后段信息"的注意力塌陷问题；
3. **多智能体协作方式另辟蹊径**：异步"黑板"共享状态模式从根本上避开了传统 P2P 智能体消息广播的状态冲突、互相干扰的问题；
4. **失败与实验可复现性细节诚意较足**：尽力披露了上下文净化措辞、退化恢复机制、相似度阈值等细节，使方法和消融逻辑相对可复现并可自洽；
5. **统计检验覆盖和消融方向的逻辑链条清晰**，把"能否完成任务"归于 DAG 与调度状态，把"完成效率"归于意图指导，整体逻辑自洽。

4. **数据防泄漏存在残余风险**：黑名单可能漏掉改写或旁支式的 writeup，这种风险现实存在，论文自己也承认难以完全消除。
5. **恶意/对抗性污染防御讨论尚浅**：离线意图图的投毒风险、检索语料污染、动态边注入等，论文都只在 "threat modeling" 层面简要提及，说明降低了执行危害，但并未给出针对对抗性图谱污染的实证，也没有对"安全边界漏洞被刺穿后的后果"做鲁棒性测试。
6. **方法上依然依赖较强的术语建模门槛**：整套体系需要将目标系统、任务过程、依赖关系手工整理成型的大量约束、语义表结构；从推广价值看，在不同网络架构、工具链或漏洞类型上是否很容易迁移适配仍待验证（没有在真实内网渗透测试项目上报告）。

### 总体评价

整体而言，Intentest 抓住当前 LLM 安全智能体的痛点——无法自持的"长时上下文——但在某个任务上综合了一个在工程上可落地的手段：用**持久事实约束、结构化状态外化＋多阶段战术检索**补救 LLM 对早期微事实的掌控力。尽管 CTF 数据规模仍旧偏小，无法直接拿到真实企业内网做对照实验，其明确的构造方式、因果约束闭环、统一大模型的质量对比、以及统计显著的排序 / 效率优势，在一定程度上证明了该方法对长时域渗透测试的

...积极意义。

**理论贡献层面**，该工作的核心价值在于把"智能体的记忆"从一个不可观测、不可校验的推理内部变量，转变为一个**可审计、可验证、可回滚的外部因果约束系统**。这既是工程上的一次可复用抽象——图结构与检索调度完全可以独立移植到其他长时域智能体任务中；也是一次安全属性上的提升——任何执行授权必须以结构证据链为准绳，而非仅依赖模型对提示词的主观服从。同时，它对多智能体间异步黑板模式的取舍也向社区传递了一个明确信号：与其追求更聪明的上下文压缩或记忆摘要，不如承认上下文窗口的物理边界，直接建立外化的持久状态层。

**应用边界层面**，需再次强调其验证情境的局限性：目前成果仍停留在"单主机 + Web 漏洞链"的 CTF 范畴，距离覆盖企业内网横向移动、跨域持久化、动态防护对抗的多阶段真实攻防尚有距离。但论文的框架本身并不绑定特定漏洞类型或网络拓扑，其事实-意图 DAG、前置条件校验与分层调度原则在概念上具备向更广泛网络空间安全自动化任务推广的潜力——这或许是它对当前 LLM 安全智能体演进路线最大的启示意义。

**总体研判**：Intentest 的贡献不在于让模型"想得更深"，而在于让模型"忘不掉且不乱跑"——通过将事实与意图从上下文中剥离，固化为可检索、可校验、可追溯的持久图结构，它为长时域自主渗透测试提供了一个逻辑自洽、工程可行且经实验初步验证的状态管理范式。其遗留的短板也为后续研究指明了清晰方向：需要更大规模真实内网环境的验证、针对对抗性图谱污染的防御性实证，以及对知识库构建成本、跨场景迁移门槛的进一步优化与量化。
