## 摘要
持续的自我改进需要不断扩大的自我生成、多样化、适应性目标库。对于语言智能体而言，现有的训练环境库（人工策划、静态合成或冻结验证器）在学习者规模扩展时保持目标分布固定。我们提出SPADE（自适应合成可执行环境中的自我对弈），一种自我对弈强化学习框架，其中单个LLM扮演两个角色：一个环境设计者，编写完整的长时程训练环境作为可执行代码，采用OpenAI Gym风格的reset()/step()接口；以及一个推理智能体，学习在这些环境中行动。每个环境都是有状态的多轮环境（状态转换、奖励函数和验证代码），因此一个接口即可涵盖推理问题和多步骤智能体工具使用。推理智能体的遗憾通过其有/无特权提示的奖励差距来估计；在优化这一遗憾信号的过程中，环境设计者学会针对智能体能力边缘的环境进行设计，同时保持其可行性。通过大量实验，我们发现几个对成功至关重要的组件：将环境设计者锚定在从大型预训练语料库中采样的文档上，并赋予其累积的环境记忆。扩展到300亿参数模型时，SPADE在八个保留的数学、科学、代码和推理基准上平均比最强的固定环境基线提升+5.3，在BFCL-v4多轮工具使用设置中提升+5.7，在ACEBench-Agent上提升+13.9；在游戏设置中，相对于最强基线的优势随模型规模增长。通过使环境设计本身成为可学习组件，SPADE向开放式自我改进迈出了具体一步。

## Abstract
Continuous self-improvement requires an ever-expanding pool of self-generated, diverse, adaptive goals. For language agents, existing training environment pools (hand-curated, statically synthesized, or frozen-verifier) keep the goal distribution fixed as the learner scales. We introduce SPADE (Self-Play in Adaptive Synthetic Executable Environments), a self-play RL framework in which a single LLM plays two roles: an Environment Designer that writes complete, long-horizon training environments as executable code with an OpenAI Gym-style reset()/step() interface, and a Reasoning Agent that learns to act in them. Each is a stateful, multi-turn environment (state transitions, reward functions, and verification code), so one interface spans reasoning problems and multi-step agentic tool use. The Reasoning Agent's regret is estimated using the gap between its reward with and without privileged hints; in optimizing this regret signal the Environment Designer learns to target environments at the edge of the agent's capabilities while keeping them feasible. Through extensive experimentation, we find several components critical to success: grounding the Environment Designer on documents sampled from a large pretraining corpus, and giving it an accumulated environment memory. Scaling to 30B-parameter models, SPADE improves over the strongest fixed-environment baseline by +5.3 on average across eight held-out math, science, code, and reasoning benchmarks, and lifts the tool-use setting by +5.7 on BFCL-v4 multi-turn and +13.9 on ACEBench-Agent; on the games setting, the margin over the strongest baseline grows with model scale. By making environment design itself a learnable component, SPADE takes a concrete step toward open-ended self-improvement.

## 1. 论文的核心问题与整体含义

**研究背景与动机**：

- 语言智能体（LLM Agent）的能力提升越来越依赖于"经验学习"——模型通过与环境互动获得的轨迹和奖励来进行强化学习训练。
- 高质量人类文本是有限资源，因此训练环境的供给成为智能体进一步发展的瓶颈。各大实验室环境预算已超过每年10亿美元，仍不足以应对需求。
- 现有训练环境库存在三方面局限：
  - **人工策划的环境**（如 AgentRL、TextArena）：扩展速度受限于人力的写作速度；
  - **静态合成环境**（如 RLVE、AWM、ScaleEnv）：生成器固定，环境分布不随学习者能力提升而增长，智能体学完即停滞；
  - **冻结验证器**：验证器无法与环境协同演化。
- 现有自我对弈方法（如 SPIRAL、SPICE、AZR、R-Zero）主要生成"任务"（一个仅有稀疏终结奖励的问题），而非完整的多轮环境（含状态转移、奖励函数和验证代码），且受限于信息对称性，容易坍塌。
- 核心研究问题：**如何让训练环境分布随智能体的能力提升而自适应地、持续地增长，从而实现开放式自我改进？**

**核心思想**：将环境设计本身变成一个可学习的组件，通过自我对弈的方式让单个 LLM 同时扮演"环境设计者"和"推理智能体"两个角色，使两者协同演化——智能体提升的同时，训练环境也变得更复杂、更具挑战性。

## 2. 论文提出的方法论

**核心思想：双角色自我对弈（Dual-Role Self-Play）**

- 单个 LLM（πθ）通过角色特定的系统提示词扮演两个角色：
  - **环境设计者（Environment Designer, ED）**：生成可执行的 Python 环境（Gym 风格 reset()/step() 接口），同时为每个环境生成特权提示（privileged hint）；
  - **推理智能体（Reasoning Agent, RA）**：与环境交互、学习解决任务。
- 两个角色共享参数 θ，通过 GRPO 算法联合更新。

**核心技术一：代码即环境（Code-as-Environment）**

- 环境以 Python 程序形式表示，实现 Gym 风格的 `reset()`/`step()` API，编码完整的 MDP（状态空间、转移函数、奖励函数、验证代码）。
- 任意可计算 MDP 都可以表示为 Python 程序，因此环境设计者可以表达任何此类环境，而不受限于手工设计的参数化空间。
- **一个统一接口同时涵盖**：
  - 单轮推理任务（`reset() → step(answer) → terminal reward`）；
  - 多轮智能体工具使用任务（`reset() → step() → ... → done`）。

**核心技术二：基于提示的遗憾奖励（Hint-Based Regret Reward）**

- 环境设计者的奖励定义为：

  **rD(e) = r̄A(e | h) − r̄A(e)**

  其中：
  - r̄A(e | h)：推理智能体在带提示 h 条件下的平均回报（G 条 rollout 的平均）；
  - r̄A(e)：无提示条件下的平均回报。
- **三种状态**：
  - 高遗憾 → 环境正好处于学习前沿（有提示能解决，无提示不能解决）；
  - 低遗憾且两臂都成功 → 环境已被掌握；
  - 低遗憾且两臂都失败 → 环境不可解。
- 该奖励实现了 PAIRED（Dennis et al., 2020）中的 minimax regret 目标，但不需要单独的对抗者——带提示的推理智能体充当上界策略。
- 理论分析（附录 B）证明：在理想化假设下，任一纯纳什均衡都能在每一有效环境上实现无提示最优性。

**核心技术三：语料库锚定与环境记忆（Corpus Grounding + Environment Memory）**

- **语料库锚定**：每轮环境设计者从外部语料库中采样新鲜文档作为条件输入：
  - 游戏场景：DCLM（10k数学文档）和 MegaScience（5k科学文档）；
  - 工具使用场景：Nemotron 预训练代码语料库（15k文档）。
  - 目的：打破"看不见的牵绳"（invisible leash），防止生成器模式坍塌和同质化。
- **环境记忆**：维护一个跨回合的缓冲区，存储过去生成的环境及其遗憾分数和技能标签：
  - 为设计者提供高遗憾种子以供变体生成；
  - 提供过易/过难示例以避免重复；
  - 使每轮都从智能体当前最难的环境开始，而非从零开始。

**训练稳定性技术**：

- 按角色独立标准化优势（per-role advantage normalization）；
- 对较少的环境设计者轨迹进行上采样（upweight）；
- 延迟环境设计者更新 k 步，并使用截断重要性采样（truncated importance sampling）做离策略修正；
- 非对称裁剪区间（ε_low=0.2, ε_high=0.28）；
- 遗憾下限化（floor at zero）；
- 难度锚定（difficulty anchor）：奖励 Reasoning Agent 胜率落在目标区间 [0.4, 0.6] 的环境。

**算法流程（Algorithm 1）**：

1. 每轮采样领域提示词 pd，生成 B 个候选环境 eb；
2. 验证环境（语法、可执行性），丢弃无效环境；
3. 为每个有效环境生成提示 hb；
4. 推理智能体分别在无提示和有提示条件下各执行 G 条 rollout；
5. 计算环境设计者奖励 rD(eb) = r̄A(eb|hb) − r̄A(eb)；
6. 分别计算两角色的组标准化优势，联合更新策略 πθ。

- **定性分析**：环境多样性（Vendi 分数）、环境质量（可学习份额、良构性、可验证性、奖励粒度）、智能体行为演化（早期 vs. 后期 episode 对比）。

### 充分性与公平性评估

**优点**：
- 固定的 400 迭代训练预算保证了基线对比的公平性；
- 每个骨干的基线都从相同基础检查点重新训练；
- 评估基准均不参与训练，无数据泄漏；
- 消融设计较为系统，逐项分离各组件贡献。

**不足**：
- 工具使用场景中与四个参考系统的对比使用转录分数，各系统在训练数据、预算、基础模型和评估协议上存在差异（文中附录 C.3.1 有说明），**不是严格的控制变量对比**；
- 消融实验仅在 30B-A3B 一个模型上进行，未验证跨规模的一致性；
- 论文中"可学习份额"（learnable fraction）等指标的部分数据来源（每步日志）未完全公开，仅报告了摘要级结果；
- 部分消融控制同时改变多个因素（如自生成控制同时移除 ED 训练和记忆），无法完全隔离单个因素的贡献。

**总体而言，实验较为充分且设计合理，但跨系统对比的公平性受限于转录分数的固有差异。**

## 6. 论文的主要结论与发现

1. **游戏场景下全方面提升**：
   - 30B-A3B 上，SPADE 八基准平均 58.3 分，超过基础模型 +8.1，超过最强固定环境基线（Fixed-env RLVE）+5.3；
   - 程序推理（Reasoning-Gym）增益最为显著（RG-Math +18.3、RG-Algorithmic +14.1、RG-Cognition +14.7）；
   - 竞赛数学保持不退化，科学推理和代码生成均有提升；
   - 优势随模型规模增大而扩大（4B：+5.2，8B：+5.7，30B-A3B：+8.1）。

2. **工具使用场景下显著增益**：
   - 30B-A3B 上 ACEBench-Agent +13.9、BFCL v4 multi-turn +5.7、τ2-bench +3.6；
   - 4B 上 BFCL v4 multi-turn +10.3；
   - 在 BFCL v4 multi-turn 和 ACEBench-Agent 上超越所有四个专用数据合成系统。

3. **渐进课程涌现**：SPADE 从简单单技能任务进展到需要长时程交互的多约束环境。环境设计者学会在提示中隐藏解法公式（揭示率从 25% 降至 5%），奖励粒度从 3.7 级增至 5.8 级。

4. **语料库锚定是多样性的关键**：去除语料库后，环境 Vendi 分数从 0.68 崩溃至 0.04（同一旋转迷宫任务连续生成 41 次）。

5. **自我对弈的完整配置至关重要**：部分消融只恢复约 35% 的增益；去掉 ED 训练和记忆后，模型甚至比不训练还差 9.7 分。

6. **提示遗憾优于 EMA 学习潜力信号**：提示遗憾 +8.1 vs. EMA +5.7 的八基准平均增益。

7. **推理智能体的行为发生质变**：从早期"事先推导、无法恢复格式错误"转向后期"先收集证据、再一次性推导"的证据优先交互策略。

## 7. 优点

1. **范式创新**：首次将环境设计本身变为 RL 训练的可学习组件，而非固定生成器或手工参数化空间的搜索，为开放式自我改进提供了具体路径。

2. **统一接口设计**：代码即环境的 Gym 风格接口统一了单轮推理和多轮智能体工具使用，一个框架、一套管线覆盖两个差异很大的设置，展示了良好的泛化性。

3. **提示遗憾奖励兼顾前沿与可行性**：与纯粹对抗（可生成不可解环境）和纯粹合作（可虚增奖励而无所教）不同，提示遗憾在两者之间取得平衡，从理论（纳什均衡分析）和实验两方面验证了有效性。

4. **有效解决自我博弈坍塌**：语料库锚定（打破信息对称性、提供外部新颖性）与环境记忆（防止重复已掌握任务）双重机制，保持了环境多样性 Vendi 分数稳定在高位（0.68），且 97% 的训练步产生全新环境。

5. **规模化验证与实用配方**：在 30B-A3B 规模上验证了有效性，提供了完整的训练配方（环境验证、奖励黑客防护、课程设计），并证明了跨模型家族（Qwen3、Nemotron）的可迁移性。

6. **实验设计严谨**：统一的 400 迭代预算、逐检查点的评估曲线、全面的消融体系，以及定性定量结合的分析方式。

7. **丰富的定性洞察**：通过真实生成环境示例、智能体行为轨迹分析和课程演化的可视化，使读者能够直观理解方法的工作原理。

## 8. 不足与局限

1. **复杂度受限于模型规模和"看不见的牵绳"**：环境设计者无法生成比其基础模型在上下文中能表达的更复杂的环境。可达到的环境复杂度随模型规模和生成预算增长，但受限于 LLM 本身的表达能力。

2. **优化器仍然是人类设计的**：两个角色都由固定的人类编写的 RL 算法（GRPO）更新，SPADE 本身不修改其学习规则，并非完全自我改进系统。

3. **缺乏形式化最优性保证**：提示遗憾奖励虽然受到 PAIRED 理论启发，但并未被证明能够产生最优课程。均衡分析基于理想化假设（如提示可达最优值等），实际场景中不完全成立。

4. **评估仍是固定任务基准**：当前基准衡量的是固定任务上的表现，而非开放式推理能力的持续增长。这无法直接证明 SPADE 实现了真正意义上的"开放式"改进。

5. **与参考系统的对比不严格**：工具使用场景与 AgentScaler、AWM 等系统的比较使用了转录分数，存在训练数据、基础模型和评估协议的差异，非严格公平对比。

6. **消融实验的覆盖不足**：
   - 消融仅在单一骨干（30B-A3B）上进行；
   - 部分控制同时改变多个变量，无法精确归因；
   - EMA 奖励的对比中，第三个对照（无 ED 训练和无记忆）无法隔离 ED 训练与记忆的贡献。

7. **实验成本信息缺失**：未报告 GPU 时长、硬件配置等关键资源信息，影响实际应用中的成本评估。

8. **工具使用评估的基准匹配度差异**：SPADE 在 ACEBench-Agent 上增益最大（+13.9），但 τ2-bench 增益较小（+3.6），表明生成环境与特定基准结构的匹配程度影响了迁移效果，泛化并非全面均匀。

9. **对小模型上遗憾信号的噪声**：4B 和 8B 模型的提示遗憾估计在训练长时间段内为负（尽管最终仍有提升），说明该信号在小规模上不够稳定。
