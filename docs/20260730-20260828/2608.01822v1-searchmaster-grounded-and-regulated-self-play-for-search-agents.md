## 摘要
训练基于LLM的搜索代理需要高质量的搜索数据：这些任务需要真正的多跳检索以及有效使用搜索工具的轨迹。现有的流程通常依赖人工编写的任务、专家示范或更强的教师模型。我们提出了SearchMaster，一种自我对弈框架，它从一个本地搜索环境中由单个LLM生成、解决并验证的搜索任务中训练该LLM。关键挑战在于，自我生成的任务和轨迹可能产生误导性信号：伪多跳问题、忽略搜索深度的成功率难度估计，以及过多打开文档但缺乏针对性证据获取的轨迹。SearchMaster通过三种控制来解决这些失败模式。证据链生成器（ECG）将任务生成锚定在显式的跨文档证据链上，以减少伪多跳问题。搜索深度奖励（SDR）根据成功轨迹的搜索深度而非仅依据成功率来评分任务难度，从而确保保留的任务具有搜索密集性。过度打开惩罚（OOP）通过阻止过度打开文档来规范工具使用，避免长时间但浅层的浏览。经过验证的提议者和求解者轨迹随后通过GRPO联合优化。在六个深度搜索基准上，SearchMaster将Qwen3.5-9B骨干的平均准确率从38.19%提升到51.52%，在BrowseComp-Plus上获得了30.1分的提升。这些结果表明，基于事实与受调控的自我对弈可以在无需人工标注的问答对或专家示范的情况下，提供有效的搜索代理训练数据。代码可在https://github.com/WentaoTan/SearchMaster获取。

## Abstract
Training LLM-based search agents requires high-quality search data: tasks that demand genuine multi-hop retrieval and trajectories that use search tools effectively. Existing pipelines often depend on human-written tasks, expert demonstrations, or stronger teacher models. We present SearchMaster, a self-play framework that trains a single LLM from search tasks it generates, solves, and verifies in a local search environment. The key challenge is that self-generated tasks and rollouts can yield misleading signals: pseudo multi-hop questions, success-rate difficulty estimates that ignore search depth, and rollouts with excessive opening but little targeted evidence acquisition. SearchMaster addresses these failure modes with three controls. An Evidence-Chain Generator (ECG) grounds task generation in explicit cross-document evidence chains to reduce pseudo multi-hop questions. A Search-Depth Reward (SDR) scores task difficulty by the search depth of successful rollouts rather than success rate alone, keeping retained tasks search-intensive. An Over-Opening Penalty (OOP) regulates tool use by discouraging excessive document opening, avoiding long but shallow browsing. Verified Proposer and Solver rollouts are then jointly optimized with GRPO. Across six deep-search benchmarks, SearchMaster improves a Qwen3.5-9B backbone from 38.19% to 51.52% average accuracy, with a 30.1-point gain on BrowseComp-Plus. These results show that grounded and regulated self-play can provide effective search-agent training data without human-labeled QA pairs or expert demonstrations. The code is available at https://github.com/WentaoTan/SearchMaster.

- 自我对弈（self-play）被认为是一种自然解法——模型可以自己生成任务并学习解决，但搜索代理场景下自我对弈面临独特困境：**自生成的任务和轨迹看似有用，实则可能提供误导性监督信号**。

**三个核心失败模式：**
1. **伪多跳问题（Pseudo Multi-Hop）**：模型可能浏览多篇文档，但最终提出的问题仅凭单篇文档即可作答。
2. **难度评估偏差**：仅凭成功率评估任务难度，无法区分浅层查找任务与真正需要多步搜索的任务。
3. **过度打开文档（Over-Opening Drift）**：模型逐渐过度依赖打开文档，重复回看已见内容，产生"长而浅"的浏览轨迹，而非针对性获取证据。

## 2. 方法论：核心思想与技术细节

### 2.1 总体框架

SearchMaster 训练**单一策略 πθ**，使其在本地搜索环境中同时扮演两个角色：
- **Proposer（提议者）**：生成多跳搜索任务
- **Solver（求解者）**：通过浏览器工具（search、open、find）解答任务
- **Verifier（验证者）**：冻结的初始模型副本，评估任务质量和答案正确性

核心流程：种子文档 → Proposer 生成候选任务 → 质量过滤器筛选 → Solver 独立求解 → 冻结 Verifier 判定 → SDR/OOP 奖励计算 → GRPO 联合优化。

### 2.2 三个关键控制机制

**(1) 证据链生成器（Evidence-Chain Generator, ECG）**

- 要求 Proposer 在探索过程中**增量式构建显式跨文档证据链** c = e₁ → e₂ → … → eₙ，再基于完整证据链生成问题。
- 形式化：从种子文档 d 出发，Proposer 采样 K_P 条任务生成轨迹：(τ_Pj, c_j, q_j, y⋆_j) ~ πθ(·|P_prop, d)
- 四个质量过滤器：工具使用量过滤、格式过滤（证据链至少含两项）、有效性过滤（Verifier 判断逻辑合理性）、参数知识过滤（确保问题无法在无工具情况下作答）。

**(2) 搜索深度奖励（Search-Depth Reward, SDR）**

- 核心创新：用**最浅成功搜索深度** h_min（而非成功率）衡量任务难度。
- h_min = min{hi : zi = 1}，其中 zi 为第 i 条 Solver 轨迹的正确性，hi 为该轨迹的唯一搜索查询数。
- 若任何成功轨迹用浅层搜索就能解决，说明任务存在捷径，不应获得高难度奖励。
- 公式：r_sdr = r₀ + (1 − r₀)·min(h_min / H_sdr, 1)，H_sdr 为奖励饱和的目标深度。

**(3) 过度打开惩罚（Over-Opening Penalty, OOP）**

- 惩罚 open 与 search 动作的比例（而非原始打开数），避免抑制合理多文档探索。
- 公式：ρ_oop(τ) = clip((n_open/n_search − α_oop)/(β_oop − α_oop), 0, 1)
- α_oop = 1.5（开始惩罚的阈值），β_oop = 2.5（惩罚达到最大值的阈值），λ_oop = 0.5。

### 2.3 奖励设计与优化

**Proposer 基础奖励：**
- 过滤器失败：−0.5 至 0.1（按失败类型区分）
- C = 0 或 C = K_S（全部失败或全部成功）：低基础奖励 r₀ = 0.2
- 其余情况：r_sdr

**Solver 基础奖励：**
- 无工具调用：−0.5；格式无效：0；否则：正确性得分 zi

**GRPO 优化：**
- 每个保留种子文档贡献两个 GRPO 组：Proposer 组（K_P 条任务生成轨迹）和 Solver 组（最高奖励任务的 K_S 条求解轨迹）。

## 6. 主要结论与发现

1. **自我对弈可以有效训练搜索代理**：SearchMaster 将 Qwen3.5-9B 在六个基准上的平均准确率从 38.19% 提升至 51.52%（+13.3 点），全程无需人工标注数据或专家示范。

2. **离线训练可迁移到在线搜索**：尽管完全在本地离线语料库中训练，模型在五个实时网络搜索基准上均取得显著提升（+6.8 至 +18.2 点），证明学到的搜索行为具有跨环境泛化能力。

3. **三个控制机制协同发挥作用**：
   - ECG 将真多跳任务比例从 24.2%（naive）提升至 78.6%（训练后），无效任务从 28.7% 降至 6.4%
   - SDR 使训练任务的搜索深度 h_min 保持在 8–10 范围，而成功率信号下会衰减至 2–3
   - OOP 有效抑制 open/search 比率的持续上升，且不影响合法多文档探索

4. **9B 模型可达超大模型水平**：训练后的 9B 模型在 BrowseComp-Plus 上（60.24%）超过 gpt-oss-120B-high（42.89%）、GPT-4.1（35.42%）和 Claude Opus 4（36.14%），接近 OpenAI o3（63.49%）。

## 7. 优点

1. **问题定义精准**：明确识别搜索代理自我对弈的三个独特失败模式（伪多跳、难度误判、过度打开），并逐一给出针对性解决方案，而非笼统地"生成更多数据"。

2. **方法论自洽**：每个控制机制都与其要解决的问题形成严格对应关系——ECG 锚定事实基础、SDR 校准难度信号、OOP 调控工具行为，逻辑链条清晰。

3. **行为验证范式**：消融实验不仅报告最终指标，还验证每个机制是否产生**预期的可观察行为变化**（如 h_min 的保持、open/search 比率的变化），这种"机制→行为→性能"的验证链条值得借鉴。

4. **h_min 的设计巧妙**：用最浅成功搜索深度（而非平均或最大深度）衡量任务难度，能有效检测任务中的"捷径"，防止浅层任务冒充高难度任务。

5. **OOP 的设计合理**：惩罚 open/search 比率而非绝对打开数，既能限制冗余浏览，又不会惩罚合法多文档深度探索任务。

6. **无外部依赖**：完全依靠本地搜索环境+自生成数据实现训练，代码和检查点将开源，可复现性强。

## 8. 不足与局限

1. **骨干模型单一**：仅验证了 Qwen3.5-9B 一个骨干模型，方法的通用性（跨模型规模、跨模型家族）未得到验证。

2. **训练语料单一**：仅在 OpenResearcher 离线语料库上训练，尽管在线基准显示一定泛化能力，但离线语料可能无法覆盖开放网络的多样性和动态性（作者在结论中亦承认此点）。

3. **训练成本较高**：每轮需 64 种子 × 8 Proposer 轨迹 × 8 Solver 轨迹（每条最多 200 次工具调用）加上 Verifier 的多重调用，计算开销显著；且论文未量化总训练成本。

4. **验证者能力瓶颈**：冻结的初始模型作为 Verifier，其判断能力构成上限。若初始模型能力不足，可能漏掉有效任务或误判正确答案，论文未对此风险进行敏感性分析。

5. **在线基准的覆盖有限**：虽然在线基准表现提升，但 GAIA、WebWalkerQA 等任务的绝对准确率仍偏低（57.28%、59.71%），与顶尖模型（如 MiroThinker-72B 在 GAIA 上 81.90%）差距明显。

6. **种子级门控的数据效率**：所有候选任务失败（奖励 ≤ r₀）的种子文档会被整体丢弃，这可能导致部分有潜在价值的任务被浪费，数据利用效率有提升空间。
