## 摘要
自我对弈智能体无需来自目标基准的问题即可生成训练问题，但它们的课程缺乏持久状态：失败会影响梯度，却不会明确地塑造未来的实践。外部技能记忆保存了程序性经验，但通常是从固定的任务分布中学习的。我们引入了SESA（自进化技能增强智能体），它使程序性记忆成为工具增强的搜索自对弈的进化状态。挑战者提出问题，而单独参数化的求解器仅负责检索技能。有信息量的失败被提炼为可复用的技能并写回记忆。更新后的记忆改变了求解器的行为和成功率，进而改变了挑战者的奖励和未来问题的分布；由此产生的前沿会带来新的失败，从而重写记忆。这种双向循环使任务生成和技能记忆共同进化。由于检索到的技能塑造了同策略训练轨迹，它们的好处可以进入模型参数，同时保留在外部库中，从而实现无需记忆的部署和可选的推理时检索。在七个开放域和多跳问答基准上，SESA在多种骨干网络上的平均准确率比SSP提高1.2-3.2个百分点，并在统一评估协议下超越技能增强的SkillRL基线0.9个百分点。在Qwen3模型上，SESA-Off比SSP保持1.8-2.2个百分点的提升，而最终技能库额外增加0.5-1.0个百分点。这些结果表明，进化的技能记忆不仅仅是推理时的插件：它改变了策略学习和未来的训练分布，同时保留作为可选外部记忆的价值。我们的代码可在https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents获得。

## Abstract
Self-play agents can generate training problems without questions from target benchmarks, but their curricula lack persistent state: failures affect gradients yet do not explicitly shape future practice. External skill memories preserve procedural experience but are typically learned from fixed task distributions. We introduce \textbf{SESA} (Self-Evolving Skill-Augmented Agent), which makes procedural memory an evolving state of tool-augmented search self-play. A challenger poses problems, while a separately parameterized solver alone retrieves skills. Informative failures are distilled into reusable skills and written back to memory. The updated memory changes solver behavior and success, which changes the challenger's reward and the distribution of future problems; the resulting frontier produces new failures that rewrite memory. This bidirectional loop makes task generation and skill memory co-evolve. Because retrieved skills shape on-policy training trajectories, their benefits can enter the model parameters as well as remain in the external bank, enabling memory-free deployment and optional inference-time retrieval. Across seven open-domain and multi-hop question-answering benchmarks, SESA improves average accuracy over SSP by 1.2--3.2 points across multiple backbones and surpasses the skill-augmented SkillRL baseline by 0.9 points under a unified evaluation protocol. On Qwen3 models, SESA-Off retains 1.8--2.2 points of improvement over SSP, while the final skill bank adds a further 0.5--1.0 points. These results show that evolving skill memory is not merely an inference-time plug-in: it changes policy learning and the future training distribution while retaining value as optional external memory. Our code is available at https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **现有方法的两条互补路线及其缺陷**：
  - **自我对弈（Self-Play）** 路线（如 SSP）：智能体可以在没有外部问题集的情况下自主生成问题并求解，但其课程缺乏**持久状态**——失败只产生策略梯度，随后即被丢弃，不会显式塑造未来的练习内容。
  - **技能增强强化学习（Skill-Augmented RL）** 路线（如 SkillRL）：将经验蒸馏为可检索的技能并存入外部记忆，保留程序性知识，但通常从**固定的任务分布**或人工设计的课程中学习。
- **核心矛盾**：自我对弈决定了练什么，但遗忘教训；技能增强 RL 记住了教训，却无法自主选择任务。二者互为镜像，缺少一个既能自主选择练习前沿、又能持久保留失败教训的统一框架。
- **本文目标**：提出 **SESA（Self-Evolving Skill-Augmented Agent）**，将程序性记忆作为工具增强搜索自我对弈的**演化状态**，使任务生成与技能记忆形成双向闭环、共同进化。

## 2. 论文提出的方法论

### 2.1 核心思想

SESA 构建了一个"**失败 → 技能 → 求解器 → 新失败**"的闭环：
- 挑战者（Challenger/Proposer）提出可验证问题；
- 求解器（Solver）独立检索技能并尝试求解；
- 有价值的失败被蒸馏为可复用技能，去重后写回外部记忆；
- 更新后的记忆改变求解器行为，进而改变挑战者的奖励与未来问题分布；
- 新分布产生新失败，再次改写记忆，形成协同演化。

### 2.2 四个关键阶段

1. **记忆启动（Memory Priming）**：用 15 条人工编写的技能 + 142 条从早期自我对弈引导中挖掘的技能初始化技能库（共 157 条），提供初始检索基础并锚定技能蒸馏的粒度。

2. **非对称自我对弈（Asymmetric Self-Play）**：
   - 挑战者和求解器使用**分离参数**的策略；
   - 技能**仅对求解器可见**，挑战者无法直接观测到求解导向的记忆，防止技能泄漏，维持博弈的非对称性。

3. **前沿塑造（Frontier Shaping）**：
   - 用 `p̂s(x)` 表示求解器在问题 x 上的求解成功率（G 次采样的成功比例）；
   - 不为全部失败收集技能，而是用**钟形端点惩罚奖励**引导挑战者提出难度在求解器能力边界附近的问题：
     - `p̂s = 0`（完全不可解）和 `p̂s = 1`（完全可解）时给予惩罚 -λ；
     - 中间成功率获得较高奖励，鼓励挑战者持续生成"求解器恰好做不好但并非无解"的问题。

4. **失败蒸馏（Failure Distillation）**：
   - **检索**：训练前用稠密编码器检索 top-k 技能（k=3），前置到求解器提示中；
   - **失败收集**：求解失败的轨迹被压缩为包含问题、目标、预测、检索证据等信息的记录，进入 300 条容量的待处理队列，每 10 步合并一次，最多选 30 条（优先重复失败和检索了技能仍失败的样本）；
   - **合并**：由评判模型将失败抽象为技能卡片（含触发条件、判别证据、规避线索、查询模板等），E5-base-v2 余弦相似度 ≤ 0.93 才允许入库；
   - **维护**：种子技能永久保留；非种子技能若检索 ≥3 次且（有用数 - 伤害数）为负则被淘汰；超过 800 条时删除得分最低的非种子技能。

### 2.3 关键公式与训练目标

- 技能存储形式：`s = (u, c, a, z, m)`——描述、触发条件、规避提示、查询模板、使用元数据；
- 技能检索：`R(q; Bₜ) = TopK sim(e(q), e(s))`；
- 求解器使用 **GRPO**，每次对同一问题采样 G 条搜索轨迹，奖励为可验证的答案正确性（先规范化精确匹配，再由模型做语义匹配）；
- 使用挑战者的奖励是前沿塑形奖励 `rₚ(x)`，而非简单的 1−p̂s。

### 2.4 双路径技能复用

- **SESA-Off（无记忆部署）**：`π_off(τ|q) = π_θT(τ|q, T)`——技能通过训练期间塑造的同策略轨迹内化进模型参数；
- **SESA-On（记忆增强部署）**：`π_on(τ|q) = π_θT(τ|q, T, R(q; B_T))`——推理时额外启用最终技能库检索。
- 二者的差距纯来自推理时检索的贡献，从而将技能收益分解为**参数化迁移**和**非参数化检索**两条路径。
